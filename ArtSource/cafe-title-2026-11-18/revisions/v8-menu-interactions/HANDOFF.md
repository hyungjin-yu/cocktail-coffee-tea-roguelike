# 카페 메뉴 접근·조작 아트 계약 v8

**초안 보관.** 구현에는 관찰자 시점과 실제 물체 조작을 적용한 [v9 인계서](../v9-menu-clips/HANDOFF.md)와 [v9 layout](../v9-menu-clips/layout.json)을 사용한다. 아래 배우 보행 경로는 폐기했다.

[조작 계약](interaction-contract.json)은 v7 화면을 기준으로 8개 물체의 발 경로, 접점, 조작 동작과 길이를 정의한다. [접근 경로 비교](approach-anchor-proof.png)의 금색 선은 발 경로, 청록색 점은 손이 닿는 위치다. 480×270 투영에 맞춰 잡았으며 배우의 발 위치를 기준으로 contain 변환과 원근 크기를 적용한다. 발의 선분을 1% 간격으로 샘플링해 가구 및 열린 문짝 여유가 반경 0.13m 이상임을 확인했다.

| 메뉴 | 조작 / 재사용 | 필요한 분리와 가림 |
|---|---|---|
| 시작 | g1 상판의 가까운 컵을 집어 같은 쟁반에 놓는다. | 컵과 접지 그림자를 분리한다. 쟁반 앞턱은 컵 아래, 손은 컵을 감싸는 방향이다. |
| 영구 강화 | 바 남단을 돌아 직원 통로에서 키를 누른다. 기존 `ProgressionUI/laptop_light`의 3단 점등 색과 타이밍을 사용한다. | g2 화면 사각형 안에서 점등한다. 상판은 뒤쪽 배우의 하체를 가리고 손끝은 키보드 위에 남는다. |
| 도감 | g3 중간단 책 한 권을 빼서 가슴 높이에서 펼친다. | 책, 노출되는 선반 안쪽, 손을 분리한다. 책이 빠져나오기 전에는 선반 앞턱이 책 아래를 가린다. |
| 스킨 | g4 옷걸이를 걸린 채 조금 밀고 천을 살핀다. | 레일과 고리가 접촉을 유지한다. 몸과 손은 진열장 앞, 레일은 고리 앞에서 교차하는 부분만 가린다. |
| 최근 기록 | g5 장부를 상판 지지 상태에서 책등을 축으로 펼친다. | 닫힌 표지·움직이는 표지·펼친 페이지를 별도 cel로 둔다. 장부 전체를 공중에 들어 올릴 필요가 없다. |
| 설정 | g6 라디오 오른쪽 조절기를 중심축에 고정한 채 돌린다. | 다이얼·손·작은 표시등만 움직인다. 라디오와 받침의 접지 위치를 유지한다. |
| 제작 정보 | g7 종이 아래쪽을 손끝으로 받치고 살핀다. | 핀과 게시판은 고정하고 종이 아래 모서리만 작게 움직인다. |
| 종료 | 실내 손잡이에 닿은 뒤 걸리는 각도까지 문을 밀고 기존 종료 확인을 표시한다. | 입장 뒤 75°로 가볍게 돌아오는 상태와 75°→90° 남향 문짝 클립이 선행되어야 한다. 같은 경첩축을 사용한다. 가려져 있던 거리·문턱을 드러낼 별도 배경과 문틀/문짝/유리 레이어가 필요하다. |

## 구현 순서

1. 클릭 또는 키 활성화로 목적지를 고른 뒤, 배우를 배치된 길로 걷게 한다. 기존 바텐더 걷기 프레임을 사용하고 좌우 방향 이외의 몸 방향이 달라지는 접점에서는 필요한 포즈를 추가한다. 폴리곤, 명패, 클릭/포커스 계약은 v7을 유지한다.
2. 접점에 도착하면 물체별 동작을 한 번 재생한다. 전체 화면에서 배우 발 위치는 바닥에 고정하고, 가구 간 교차가 생기는 구간은 원근 깊이에 따라 배우의 몸과 손을 나눠 합성한다. 순서는 v7 거리와 실내 쉘 → 기존 가구/배우 깊이 합성 → 조작 cel/손끝 → 명패와 메뉴다.
3. 조작 마지막 프레임이 자리를 잡은 뒤 메뉴를 연다. 닫기나 취소 시 책·옷걸이·장부 등은 마지막 프레임에서 약 0.25초 이내로 제자리로 돌리고, 접근 경로를 역순으로 돌아 원래 초점을 복구한다. 시작과 종료를 확정했을 때는 기존 전환 및 저장 보호 경로를 사용한다.

고유 클립 ID, 길이, 목표 좌표는 제작용 계약이다. v8의 신규 조작 cel 및 Unity 연결·플레이 검수는 대기 상태다. 종료 클립의 새 배경은 정적인 v7 거리 패키지와 별도로 작업한다.
