# 카페 메뉴 접근·조작 아트 v9

전체 실내에서 각 메뉴의 관찰자 구도로 부드럽게 이동한 뒤 물체별 동작을 재생한다. 시점 이동은 기존 원근으로 그린 장면을 연속적으로 프레이밍하므로 가구를 관통하지 않는다. 화면에 배우나 분리된 손을 추가하지 않았다. [8개 클립 프레임 비교](previews/actions-six-frame-strip.png)

| 메뉴 | 실제 조작 그림 |
|---|---|
| 시작 | 컵을 기존 쟁반 위에서 영업 준비 위치로 옮긴다. |
| 영구 강화 | 거치된 노트북 화면이 밝아지고 짧은 상태 표시가 들어온다. |
| 도감 | 책장 가운데 단에서 책을 받친 상태로 책등을 축으로 펼친다. |
| 스킨 | 진열장 레일 아래 걸린 앞치마를 옆으로 살짝 움직여 살핀다. |
| 최근 기록 | 카운터에 붙은 책등을 축으로 장부 표지가 넘어가고 줄이 있는 페이지가 드러난다. |
| 설정 | 라디오 다이얼이 돌아가며 표시등이 켜진다. |
| 제작 정보 | 게시물의 핀은 제자리에 있고 아래 모서리가 들리면서 내용이 보인다. |
| 종료 | 문짝이 같은 경첩에서 살짝 되돌았다가 열리고 기존 종료 확인으로 이어진다. |

## 반입

[manifest](manifest.ready.json)의 PNG 48개를 개별 `unityDestination`에 복사한다. 각 동작은 투명 480×270 PNG 6장으로, 원래 g1–g8 레이어 하나를 같은 위치·크기·순서에서 교체한다. Aseprite 원본 8개에는 원래 물체와 그 움직임으로 드러나는 배경을 별도 cel로 넣었다. 다음 물체 레이어와 바닥 조명은 원래 순서대로 그린다. [layout](layout.json)은 v7에 8개 `approach` 필드만 추가한다.

첫 프레임은 기존 물체 레이어와 픽셀 단위로 동일하다. 메뉴는 마지막 프레임이 정착한 뒤 표시하고, 돌아올 때 같은 프레임을 역재생하고 시점을 원위치로 되돌린다. 녹아들기나 임의 크기 보정 없이 기존 contain·Point 필터를 쓴다. 저이펙트에서는 시점 이동 없이 마지막 조작 프레임만 보여 준 뒤 메뉴를 연다.

Aseprite 네이티브를 다시 열어 PNG로 내보냈다. 48장 전체를 원 레이어와 개별 조작 패치의 합성 결과에 대조했으며, 앞쪽 레이어와 교차하는 조작 픽셀은 0개였다. 마지막 프레임의 전체 합성은 투영 렌더와 채널당 최대 1 차이며, 동작은 지정한 관찰자 구도 안에 있다. 라디오 다이얼은 원본 해상도에서 3×6픽셀로 작아 실제 확대 화면에서 읽히는지 확인할 필요가 있다.
