# 레이피어 찌르기 VFX 시안 v01
- 제작: Codex built-in image_gen. 원본 생성 프롬프트: prompt.txt
- PNG: 2172 × 724, RGBA, 투명 배경 확인. 원본 복사본이며 픽셀 편집하지 않음.
- preview.html: PNG 한 장에 0.12초 신장/감쇠 애니메이션을 적용한 브라우저 시안. 좌우 전환 및 느린 재생 지원.
- 의도: 벨트스크롤 측면 시점, 흰색 중심과 옅은 청록색 가장자리, 오른쪽 직선 찌르기.
- 현재 상태: 시각/타이밍 검토용. Unity 미적용, 인게임 크기·피벗·픽셀 밀도 검증 전.
- 원본에 넓은 투명 여백과 반투명 가장자리가 있으므로 최종 픽셀 아트 규격 충족을 보장하지 않음.
- Unity 적용 시 RapierWeapon의 기존 0.12초 FadeVfx 시각 효과와 연결하되 공격 판정은 별개로 유지. 현재 공격 판정은 세로 레인 전체 폭을 사용하므로 가는 궤적을 판정 범위로 해석하면 안 됨.
- 최종 SpriteRect/PPU/피벗은 실제 게임 화면에서 확인 후 확정. preview의 픽셀 크기는 월드 유닛 규격이 아님.
