| 런타임 등급 | 쓰이는 화면 | 내부 장식 | 전달 동작 | 전달 종료 / 선택 가능 |

| 2 Epic · 영웅 | 레벨업 | 자수정색 마름모 핀과 세 쌍의 측면 장식 | 양손으로 받치고 한 프레임 목례한다 | 320 / 390 ms |
| 3 Special · 특수 | 하이브리드 확정 해금 | 황동 장석, 마름모와 점을 다섯 쌍 반복 | 양손으로 받치고 두 프레임 동안 깊게 목례한다 | 380 / 450 ms |

바텐더는 옆가르마, 남색 조끼, 청록 넥타이, 금색 핀, 검은 앞치마와 메뉴 속 칵테일잔 도장을 사용한다. 티 소믈리에는 낮은 묶음머리, 세이지 조끼, 잎 핀, 갈색 앞치마와 찻잎 도장을 사용한다. 메뉴판의 크기와 두께가 앞으로 접근하는 움직임을 표현하고, 마지막 프레임에서 손이 판의 아래 모서리를 받친다.

## Unity 연결

1. 덱 추첨 및 배치가 끝난 뒤 표시되는 카드의 최고 `CardRarity`로 공통 클립을 한 번 시작한다. 예를 들어 일반·희귀·영웅이 섞이면 영웅 동작 한 번을 재생하고, 세 슬롯에는 각각 일반·희귀·영웅 장식을 적용한다. 1·2장일 때도 같은 규칙으로 가운데 정렬한다. 후보가 없으면 기존 정비 경로로 즉시 진행한다. 다시 추첨할 때는 새 후보가 확정된 시점에 현재 재생을 교체하고 중복 실행을 막는다.
2. 일반 레벨업은 `CardSelectView.Show`의 실제 직업과 후보를 사용한다. 기존 후보 풀을 유지한다. 특수는 `GameManager.BeginHybridOffer` → `HybridUnlockView.Show`에 연결하고 바텐더 특수 클립과 `ready/hybrid_special.png`를 사용한다. 현 해금 조건은 바텐더·레이피어이며, 소믈리에 특수 클립은 두 직업의 등급 애니메이션 세트를 완성하기 위해 동봉했다. `ready/card_special.png`는 카드 비율의 특수 장식이 필요한 표시에 사용한다.
3. 128×96 RGBA 스프라이트는 점 필터로 비율을 유지해 표시한다. 1920×1080 기준 384×288 UI 크기부터 확인한다. Unity 좌하단 원점에서 최종 판의 경계는 `(14,17,101,28)`, 판 가운데 선에 둔 연출 앵커는 `(64,32)`, 정규화 피벗은 `(0.5, 1/3)`다. 이 점을 기존 슬롯 묶음의 중앙(1920×1080 기준 중앙에서 Y −30) 또는 하이브리드 패널 중앙(Y +105)에 둔다.
4. `Time.unscaledDeltaTime`으로 각 프레임 시간을 누적한다. 전달 종료 시점에 마지막 포즈를 고정하고 70 ms 동안 페이드 아웃한다. 같은 시간 동안 완성된 카드 그룹을 페이드 인한다. 각 슬롯은 최종 가로 오프셋의 88%와 크기의 94%에서 출발해 최종 좌표·크기로 정착한다. 여백이 좁은 경우 배치를 고정하고 페이드만 적용한다. 기존 채우기 등장은 이 전환으로 대체한다. 프레임이나 카드에 별도의 대기 시간을 더하지 않는다.
5. 카드가 정착한 뒤 기존 `InputReleaseGate`를 새로 무장하고 키·마우스·터치 선택과 슬롯 내부 버튼을 연다. 위 표의 선택 시점은 가장 이른 시점이며 덮개·일시정지·직전 확인 입력의 해제 조건을 함께 적용한다. 입력을 쌓아 뒀다가 확정하지 않는다. 닫기, 씬 전환, 재오픈에서 이전 재생 상태를 지운다. `HitFeedback.LowEffects`에서는 전달·페이드·추가 광원 없이 정착 상태부터 표시하고 기존 입력 해제 조건만 적용한다.
6. 430×620 슬롯에는 86×124 장식을, 980×560 패널에는 196×112 장식을 맞춘다. 장식은 불투명한 내부 바탕을 포함하므로 기존 바탕 위, 아이콘·텍스트 아래에 흰색 무틴트 Image로 둔다. 장식 Image는 Raycast Target을 끄고 기존 버튼 배경과 선택 상태 피드백을 유지한다. 장식의 가운데는 단색이며 밝은 선과 문양은 둘레 7 원본 픽셀 안에 둔다. 효과 줄 폭과 정렬이 바뀌면 `safeContentPx`와 대조한다.

## 원본과 확인 범위

- `native/`에는 Aseprite 원본 13개가 있다. 전달 원본의 레이어는 복식·머리·팔·메뉴판·손가락으로 나뉘며 타임라인에서 재생 시간을 편집할 수 있다. 장식 원본에는 내부 바탕과 장석 레이어가 있다. `ready/`에는 독립 RGBA PNG 41개가 있다.
- `manifest.json`에 등급, PNG 순서, 프레임별 ms, 해상도, 앵커와 입력 타이밍을 기록했다. `verification.json`은 Aseprite 1.3.18.6 CLI로 원본 13개를 다시 내보내 PNG 41개의 RGBA 픽셀·프레임 시간·레이어 이름을 대조한 결과다. `author.py`는 Python 3.10+와 Pillow 12에서 원본·PNG·미리보기를 재생성한다. Aseprite에서 수동 수정한 뒤에는 해당 원본에서 다시 내보내고 매니페스트와 검증 자료를 갱신한다. 전체 생성 스크립트를 다시 실행하면 native 파일도 재생성된다.
- `previews/pose-comparison.png`와 등급별 GIF는 포즈 검토용이다. GIF에는 비교를 위한 마지막 포즈 정지가 들어 있다. `previews/card-comparison-720p.png`, `card-comparison-1080p.png`, `hybrid-panel.png`는 기존 게임 아이콘과 샘플 이름·수치로 합성한 정적 비교 시트다. `previews/mixed-handoff.gif`는 혼합 3슬롯 인계 모형이다. Unity 캡처 및 실제 플레이 검수는 통합 담당 작업으로 남는다.
- 근거는 기획 기준 명세 04·05·08·09·11, 2026-11-21 플레이 피드백 A 및 `coffee-brewing`의 읽기 전용 스냅샷 `7fb00e4`다. `dfcc628`으로 카드 개편의 기준을 확인하고 `CardData.cs`, `CardSystem.cs`, `DefaultHybridCards.cs`, `CardSelectView.cs`, `HybridUnlockView.cs`와 대조했다. 본 작업 트리에 루트 AGENTS.md가 없어 최신 작업본에서 확인한 `Docs/WorkNotes/2026-11-18/AGENTS.md`의 작업·검수 규칙을 따랐다.
- 외형 참조는 `Assets/_Project/Art/v1/{bartender,tea_sommelier}/frames/*_idle_right_00.png`다. 캐릭터는 이 참조를 바탕으로 손님 방향 상반신으로 다시 그렸다. 기존 캐릭터 프레임과 Unity 파일은 편집 범위 밖이다.
