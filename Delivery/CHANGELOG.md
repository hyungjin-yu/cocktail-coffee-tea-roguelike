# 1.0.0 — 2026-10-12 (사용자 피드백 반영)

- 타이틀 "시작"과 직업 선택 "바텐더"(무기 선택의 기본 무기 포함)가 화면이 뜨자마자 파란 강조로 고정돼 보이던 문제를 고쳤습니다. 마우스를 올리면 강조되고 벗어나면 사라집니다. 키보드는 첫 화살표·Tab·Enter 입력 때 기본 버튼을 보여 주고, 그다음부터 이동·확정합니다. 키보드로 화면을 넘어온 경우에는 바로 선택돼 있습니다. 기본 무기 선택값은 그대로 유지됩니다.
- 영구 강화 해금 수에 따라 일반 몬스터 등장이 늘어납니다(40): 유효 해금 1개당 +3%(최대 +60%, 20개), 일반 동시 상한 100→최대 160, 보스·소환 포함 전체 160 유지. 보스 등장 시각·보스 소환·웨이브 크기·체력/피해 성장(33)은 그대로입니다. HUD와 영구 강화 상세에서 해금 수·등장 증가율·동시 상한을 확인할 수 있습니다.
- 히든 스킬 24종(41): 이번 런의 카드·커피 노드·하이브리드·최종 형태 조합을 채우면 런당 1회 자동 해금되고 배너로 알립니다(2요소 12 · 3요소 8 · 고난도 4). 도감 "히든 스킬" 섹션에 발견이 저장됩니다(발견 전 ??? + 힌트). 화염·독 바닥 지대는 만들지 않으며 보조 효과는 연쇄되지 않습니다.
- 화상/중독 표식(42): 적 머리 위 단색 점 대신 PixelLab으로 만든 움직이는 표식 — 화상은 왼쪽 위 작은 불꽃·불티, 중독은 오른쪽 위 독방울·기포. 둘 다 걸리면 둘 다 보이고, 봉인 중엔 멈추고 흐려집니다.
- 몬스터 장판·예고(43): 커피·올리브 알코올 불·설탕 시럽 장판과 예고 테두리를 PixelLab으로 새로 만들었습니다. 그림 경계가 실제 피해 범위와 정확히 같고(예전 그림은 가로로 두 배 넓어 보였음), 예고 테두리 안쪽 링이 예고 시간에 맞춰 차오르며, 장판은 사라지기 직전 수축·흐려집니다. 반경·피해·틱·예고 시간은 그대로입니다.

# 1.0.0 — 2026-10-09 (출시 후보 갱신)

- 영구 강화 24종/5탭(32), 성장 도전 단계(33), 공격 형태 최종 강화와 원거리 초반 추첨(34), 플레이어 화염·독 지대 삭제와 직접 적중 상태(35), 카페 픽셀 UI(31)를 포함합니다.
- 영구 강화 화면 가독성 개선(38): 보유 스페셜티·해금 수를 크게 표시하고, 카드에는 이름·효과·가격·구매 상태(✓ 완료 / 밝은 구매 가능 / 자물쇠+이유)만 둡니다. 선행·클리어 조건·적용 무기와 네 무기의 다음 런 몹 성장 예측은 선택한 카드의 상세 영역에서 확인합니다(잠긴 카드도 키보드·마우스로 상세 확인). 음수 잔액 대신 "스페셜티 N 부족"을 표시합니다.
- 결과 화면 가독성 개선(38): 결과·시간·이번 스페셜티를 크게, 직업·무기·하이브리드는 보조 줄, 처치·레벨·재료는 작은 통계, seed는 접힌 상세 정보로 옮겼습니다. 뒤 전투 화면을 더 어둡게 덮고 전투 HUD를 숨깁니다(저장 실패 알림은 유지). "다시 영업 시작 [R]"이 주 버튼입니다.
- 근접 공격의 파란 반원·바닥 범위 표시를 없애고 타격 순간의 얇은 반월 베기 효과로 바꿨습니다. 티 소믈리에 검은 새 휘두르기 동작(PixelLab+Aseprite 제작)으로 공격합니다. 판정·사거리·피해·추가타는 그대로입니다.
- 무기와 손 연결 보정: 활을 몸통을 덮지 않는 크기로 줄였고, 하이브리드 티니 보우는 평소 어깨 뒤에 메고 쏠 때 앞 손으로 잡아 당깁니다. 레이피어·검·총·활의 들고 있는 각도를 동작별로 맞췄습니다.
- 커피 트리를 모두 해금하면 존재하지 않는 "다음 해금" 대신 현재 몹 성장 배율을 보여 줍니다. 도감 상세 창이 뒤 글자를 비추지 않습니다.

# 1.0.0 — 2026-10-08

- 두 직업과 네 시작 무기, 일반/엘리트 적13종, 보스4종, 카드34종과 티니 보우, 커피15노드, 영구 강화6노드, 도감과 저장v2를 포함합니다.
- 총의 시각 길이를 기존의 정확히2배로 확대하고 손 연결을 유지했습니다. 총구보다 가까운 목표에서도 전방으로 발사합니다. 전투 수치는 유지했습니다.
- 플레이어 무기 손 위치의 한 프레임 지연과 적 피격이 행동 예고를 덮는 문제를 수정했습니다.
- 증기와 돌진 예고를 캐릭터 아래 바닥층에 표시합니다. 압력 시전으로 취소된 증기 예고도 함께 제거합니다.
- 사망 집계와 저장은 즉시 확정하고, 쓰러지는 동작을 보여준 뒤 결과 화면을 엽니다. 타이틀/재시작 시 이전 결과 예약을 취소합니다.
- 결과 화면에서 일시정지 음악 덕킹이 다음 런에 남는 문제를 수정했습니다.
- QA 자동 입력·녹화·오디오 탭·부하 시나리오는 전용 검증 빌드에서만 사용합니다.

최종 검증 상태와 실제 실행 근거는 `Reports/release-candidate-2026-10-08.md` 및 `Reports/requirements-matrix.md`를 확인하세요. Steam 게시·계정 등록·결제는 이 납품에 포함하지 않습니다.
