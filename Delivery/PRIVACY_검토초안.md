# 개인정보처리방침 검토 초안 — 아직 공개용이 아닙니다

대상 앱: 칵테일 커피 티 로그라이크 Android 버전

개발자 표시명, 문의 이메일, 검증 서버 운영 주체·지역·보존 기간과 SDK 진단 수집 설정을 확정한 뒤 공개 URL로 게시해야 합니다. 이 초안을 그대로 스토어의 개인정보처리방침으로 제출하지 않습니다.

## 구현된 데이터 흐름

- 게임 진행, 설정, 스킨 장착 정보와 확인된 구매 소유권 캐시는 기기의 앱 저장 공간에 보관합니다.
- 스킨 결제는 Google Play가 처리하며 게임 개발자는 카드번호나 결제수단 비밀번호를 받지 않습니다.
- 구매 확인을 켜면 게임은 상품 ID, Google Play 구매 토큰, 설치별 무작위 식별자를 HTTPS 검증 서버에 전송합니다. 무작위 식별자는 하드웨어 식별자가 아니며 계정 로그인이 아닙니다.
- 검증 서버는 Google Play 구매 상태를 확인합니다. 구현된 서버는 상품 ID, 구매 토큰의 SHA-256 해시, 확인 시각을 기록하고 원문 토큰을 데이터베이스에 저장하지 않습니다.
- 서버는 요청 IP를 일시적으로 사용해 과도한 요청을 제한합니다. 실제 호스팅·프록시의 접속 로그 보존 설정은 배포 시 별도로 확정해야 합니다.
- 광고 SDK를 추가하는 작업은 이번 범위에 포함되지 않았습니다. Unity/결제 SDK의 자체 진단 데이터 흐름과 사용 중인 플랫폼의 수집 사항은 최종 빌드에서 확인하고 데이터 보안 설문에 반영해야 합니다.

## 공개 전 확정할 항목

1. 개발자/개인정보 문의 연락처와 표시명
2. 검증 서버 운영 서비스와 국가/지역, 처리 위탁 여부
3. 구매 확인 기록 및 서버 접속 로그의 보존 기간과 삭제 요청 절차
4. 실제 최종 SDK 설정에 따른 진단 정보 수집 여부
5. 개인정보처리방침 공개 URL과 시행일

앱 삭제 시 기기의 로컬 진행과 설정은 없어질 수 있으며, 해당 Google 계정으로 확인된 비소모성 구매는 구매 복원 절차로 다시 확인합니다. Google Play의 환불·취소 상태에 따라 소유권이 변경될 수 있습니다. Google Play 자체 계정·결제 데이터의 관리에는 Google의 정책이 적용됩니다.
