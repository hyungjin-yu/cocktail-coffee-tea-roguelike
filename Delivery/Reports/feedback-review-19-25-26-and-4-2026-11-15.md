**결정 필요**: ①이 "표현 개선" 해석 승인 여부 ②동시 보유 시 줄무늬 vs 높은 Lv 우선 ③레이피어·총에도 같은 적중 표식을 줄지(무기 무관 카드라 형평). 삭제된 플레이어 중심 화염·독 지대는 부활하지 않음.
**아트 필요(승인 시)**: `vfx_arrow_fire`, `vfx_arrow_bitter`, `vfx_arrow_dual` — 기존 화살 스프라이트와 같은 캔버스, 3프레임 꼬리, Aseprite + PixelLab.

## 4. 커피 종류 확대 — 데이터 조사(구현 전 결정 요청)

| 항목 | 현재 사실 |
|---|---|
| 추출 방식 | `CoffeeBrewMethod { EspressoMachine, PourOver, MokaPot }` — 방식마다 전투 운용(에스프레소: 멈춰 충전→샷 공속, 핸드 드립: 뜸/붓기 이속·사거리, 모카포트) |
| 재료 | 원두(기본 + 산지 원두 다수), `steamed_milk`(스팀 우유, 커피 전용 액체), 첨가 상한 `CoffeeAdditiveMax` 100mL·잔 여유 82% |
| 잔 아트 | `dl_coffee_cup`, `dl_coffee_demitasse`, `dl_coffee_mug` (+ 마스크) |
| 예시 레시피 | SCA 비율 핸드 드립(원두 17g/물 300mL), 더블 에스프레소 1:2(18g), 모카포트 3컵(16g/130mL) |

**최소안(결정 요청)**: 추출 방식 = 기존 그대로(전투 특성 유지). **완성 음료는 배합에서 판정되는 이름·잔 표현**으로 추가하고 새 전투 효과를 임의 배정하지 않는다.
- 아메리카노 = 에스프레소 + 뜨거운 물(무료 보조 자원, 새 "물 더하기" 단계) 2배 이상 → 머그
- 카페라떼 = 에스프레소 + 스팀 우유 ≥ 120mL → 라떼 잔(신규 아트)
- 플랫화이트 = 에스프레소(리스트레토/더블) + 스팀 우유 60~110mL, 얇은 거품 → 작은 잔(신규 아트)
- 카푸치노 = 에스프레소 + 스팀 우유 + **거품 단계**(새 제조 버튼, 새 재료 없음) → 카푸치노 잔(신규 아트)
- 효과: 기존 재료 효과(우유의 정의된 효과) + 추출 방식 운용만. 이름만 다른 중복 지급 없음.
- 저장: 레시피 필드 추가 없이 배합에서 판정(기존 저장·공유 코드 호환). 거품 단계만 정수 필드 1개 추가 필요(레시피 스키마 +1).
**결정 필요**: ①이 판정식 분류 승인 ②거품 단계 추가 여부(없으면 카푸치노 제외, 3종) ③물 더하기를 추출량 조절로 대신할지 ④잔 용량·헤드룸 수치.
**아트 필요(승인 시)**: `dl_coffee_latte_glass`, `dl_coffee_cappuccino_cup`, `dl_coffee_flatwhite_cup`(+ 각 `_mask`, 기존 `dl_coffee_cup`과 같은 4배 픽셀 규격·액면 마스크 규칙), 거품 층 텍스처 `dl_foam_layer`. Aseprite + PixelLab, ArtSource 원본 직접 수정 금지.

### 4 결정 반영(코디네이터 2026-11-15: 4종 구현 승인, 이름+잔만으로 충족 금지) — 용량·상한 표(적용 기준)

**게임 내부 분류 기준**이다. 현실의 라떼·플랫화이트·카푸치노에 하나의 정답 배합이 있다는 뜻이 아니며 화면에도 "게임 분류"로 표기한다.
완성 음료(스타일)는 **에스프레소 머신 추출에서만** 고른다(핸드 드립·모카포트는 기존 "기본"만). 추출(원두 12~24g, 25~45mL)·전투 운용(멈춰 압력 충전 → 샷 공속)은 그대로, 새 전투 효과 없음 — 우유는 기존 스팀 우유 재료 효과만.

| 스타일 | 스팀 우유(창고 차감) | 뜨거운 물(무료) | 거품 단계(시간) | 잔(신규 아트 전 임시) | 잔 용량 | 채움 상한 82% | 최대 합계(추출 45 + 첨가 + 거품) |
|---|---|---|---|---|---|---|---|
| 기본(기존) | 0~100mL(기존 `CoffeeAdditiveMax`, 잔 여유가 먼저 막음) | — | — | 도구별(데미타세 70·컵 280·머그 380) | 70/280/380 | 57/229/311 | 기존 그대로 |
| 아메리카노 | 0 | 120~200mL | 없음 | 머그(`dl_coffee_mug`, 기존 승인 아트) | 380 | 311 | 45 + 200 = 245 |
| 카페라떼 | 150~200mL | — | 얇은 거품(1단계, 우유의 10% 부피, 1.2초) | 라떼 잔(임시: 머그) | 340 | 278 | 45 + 200 + 20 = 265 |
| 플랫화이트 | 80~120mL | — | 얇은 거품(1단계, 10%, 1.2초) | 플랫화이트 잔(임시: 컵) | 220 | 180 | 45 + 120 + 12 = 177 |
| 카푸치노 | 60~100mL | — | 두꺼운 거품(2단계, 50%, 2.0초) | 카푸치노 잔(임시: 컵) | 240 | 196 | 45 + 100 + 50 = 195 |

- 100mL 상한 충돌 해소: `CoffeeAdditiveMax`(100)는 **기본 스타일 전용**으로 남기고, 스타일별 우유 상한(200/120/100)을 따로 둔다. 각 잔은 최대 합계가 82% 안에 들도록 정했다(헤드룸 18% 이상).
- 거품 단계: 우유가 범위 안일 때 "거품 내기" 버튼 → 1.2/2.0초 진행 후 거품 단계가 레시피에 기록. 우유량을 바꾸면 거품은 0으로 돌아가 다시 내야 한다(미리보기·검증이 같은 값 사용).
- 저장 호환: 레시피 정수 필드 `coffeeStyle`·`hotWater`·`foam` 추가(없는 예전 저장 = 0 = 기본). 공유 코드는 스타일이 있을 때만 형식 2(기존 형식 1 코드는 그대로 해석).
- 판매·런 음용·취소·회수: 기존 경로(재료 소모 = 창고 차감 1회, 취소 시 출처 유지 환불) 그대로. 주문 판정은 추출 도구·재료량 기준이라 스타일과 무관.
