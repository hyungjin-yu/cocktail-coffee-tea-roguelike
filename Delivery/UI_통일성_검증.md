# UI 통일성 점검 — 2026-10-12

갤럭시 폴드7 펼침 화면 피드백을 기준으로 직업 선택만 수정하지 않고 타이틀, 설정, 제작 정보, 도감, 스킨, 영구 강화, 연구, 카드 선택, 일시정지, 결과를 함께 점검합니다.

## 적용 기준

- 16:9보다 세로가 긴 화면은 기준 폭을 유지하고 전체 메뉴 내용을 가운데 배치합니다. 공용 카페 배경을 사용하는 메뉴에 같은 배치 규칙을 적용합니다.
- 가로가 긴 휴대폰에서는 기준 높이 1080을 확보해 연구 화면의 제목·갈래·닫기 버튼이 겹치지 않게 합니다.
- 선택 카드의 모바일 본문은 가운데 정렬합니다. HUD 설명에는 공용 프레임과 안쪽 여백을 적용합니다.
- 연구는 바텐더의 커피 연구와 티 소믈리에의 우림 연구로 구분합니다. 포인트는 커피 포인트와 우림 포인트로 표시합니다. 공용 도감은 두 직업의 연구 명칭을 함께 안내합니다.
- 모바일에는 Esc와 R 등 키보드 안내를 표시하지 않습니다. 같은 기능의 게임 재개 및 뒤로 버튼은 같은 문구 규칙을 사용합니다.
- 오른쪽 HUD의 몬스터 성장 배율 및 스폰 상한은 표시하지 않습니다. 연구·영구 강화 상세의 내부 성장 수치, 이미 추첨된 카드의 등급 확률, 플레이어용 결과창의 seed도 숨깁니다. 실제 밸런스 계산과 진단 로그는 유지합니다.
- 티 소믈리에 결과창은 차와 우림 연구 진행을 표시합니다. 첫 조작 안내는 이동, 자동 공격, 카드, 연구, 일시정지에 집중합니다.

## 검증 방식

전체 EditMode·PlayMode 검사와 별도 QA 실행본의 `ui-audit` 화면 순회를 사용합니다. Fold 1110×1000, 가로 휴대폰 1600×720, PC 1280×720에서 메뉴와 네 가지 직업·무기 조합을 확인합니다. 폴드 해상도는 사용자가 제공한 1664×1499와 같은 화면 비율입니다.

QA는 별도 저장 경로를 사용하며 일부 보상과 종료 상태를 강제로 발생시킵니다. PC의 터치 UI 모사이므로 새 APK의 실제 폴드 단말 검증 및 Google Play 결제 검증을 대신하지 않습니다.
