# 정책 출처와 표현 범위 — 음료 마스터: 공공조달 체험편

작성일: 2026-11-10 · 대상: 공모전판 브랜치 `hyungjin-yu/pps-contest-2026`

## 1. 참고한 공식 자료(유일한 정책 근거)

- 조달청 누리집 「조달업무 > 물품구매 > 총액계약 > 업무처리절차」
  https://www.pps.go.kr/kor/content.do?key=00179 (2026-11-10 열람, HTTP 200)
- 열람 방식: 웹 열람 도구로 페이지를 받아 원문 문장을 그대로 인용함. 본문 일부(5번 이후 단계 설명)는 도구가 요약만 돌려주어 **원문 확인이 안 됨** → 게임·문서에 쓰지 않음.

### 원문으로 확인한 내용(게임에 사용)

| 항목 | 원문 |
|---|---|
| 흐름도 단계명(이미지 대체 텍스트) | 1.수요발생 → 2.조달요청 → 3.조달요청접수 → 4.규격검토 → 5.구매결의 → 6.입찰공고 → 7.예정가격결정 → 8.입찰 → 9.낙찰자선정 및 계약체결 → 10. 계약체결 통보 → 11.착수계 제출 → 12.용역이행 → 13.검사/검수요청 → 14.검사검수 및 인수 → 15.영수증발급 → 16.대금청구 및 영수(수요기관 직불시) |
| 1. 수요발생 | "수요발생은 수요기관의 사업목적에 필요한 물품 및 용역의 필요에 따른 것이며, 해당예산을 확보함으로서 발생한다." |
| 2. 조달요청 | "수요기관의 장은 품명, 규격(시방서), 납기, 특수조건 및 추산가격, 배정예산 및 물품수급관리계획 반영 여부등을 기재하여 나라장터(국가종합전자조달) 시스템을 이용 조달요청한다." |
| 3. 조달요청접수 | "조달요청서는 본청 및 수요기관을 관할하는 지방청에서 접수하며 접수와 동시에 나라장터에 게재하여 일반에게 공개한다." |
| 4. 규격검토 | "정부물품은 일반경쟁을 원칙으로 가장 경제적이고 경쟁이 가능한 규격으로 구매한다." (이후 원문 미확인) |

참고: 이 페이지는 '물품구매' 메뉴지만 흐름도 11·12단계 이름이 "착수계 제출", "용역이행"으로 적혀 있다(원문 그대로). 게임 도움말에는 흐름도 단계명을 원문대로만 나열했다.

### 확인하지 못해 쓰지 않은 내용

- 검사 기한(일수), 대금 지급 기한, 공개 기간 등 수치·특례 → 게임·문서에 넣지 않음.
- 조달청의 역할을 직접 정의하는 문장은 위 페이지 원문에서 찾지 못함 → "중앙조달기관" 같은 정의 문구를 게임에 쓰지 않고, 위 원문(조달요청·접수·나라장터 게재) 범위에서만 설명.
- 공모전 공고(https://blog.naver.com/ppspr/224440256164) 원문은 이번 작업에서 자동 열람하지 않음. 접수 요건은 제출 전 공식 원문으로 다시 대조해야 함.

## 2. 게임 단계 ↔ 공식 절차 대응(게임 도움말과 동일)

| 게임 단계 | 공식 단계(원문 단계명) | 단순화·창작 내용 |
|---|---|---|
| 1 요청 확인 | 1.수요발생, 2.조달요청 | 가상 기관 요청서의 품명·수량·규격(온도·용기·원산지 표시·카페인)·납기·예산 항목을 모두 확인해야 다음 단계로 진행 |
| 2 공급안 선택 | 4.규격검토 ~ 9.낙찰자선정 및 계약체결을 **대신하는 게임 규칙** | 요청 조건·필요 수량·예산을 모두 충족한 공급안만 주문 가능. 실제 입찰·낙찰·계약 방식을 재현하지 않으며, 가장 싼 공급안이 자동으로 맞는 답이 되지 않도록 설계(임무 1·3은 최저가 공급안이 조건 미달, 임무 2는 최저가 공급안도 조건 충족) |
| 3 입고 확인·4 제조 | 계약 조건에 맞는 공급(이행) 준비 | 포장 하나씩 입고/반품 판단, 기존 다관·주전자·드리퍼·컵 아트로 붓기(길게 누르기) 제조 |
| 5 검사·검수 | 13.검사/검수요청, 14.검사검수 및 인수 | 요청 조건과 각 잔의 품명·온도·용기·재료 이력을 비교, 불일치가 있으면 납품 불가, 구체적 보완 안내 |
| 6 납품 결과 | 14.검사검수 및 인수(인수 부분) | 적합 물품만 인수, 중복 납품·중복 보상 방지, 요청→공급→검수→인수 기록 표시 |
| (미구현) | 3.조달요청접수, 5~8, 10~12 세부, 15.영수증발급, 16.대금청구 | 다루지 않음 |

## 3. 오인 방지 문구(게임 안 실제 표시 위치)

- 타이틀 하단 상자: "이 게임은 공공조달의 요청·준비·확인 흐름을 단순화한 창작 체험입니다. / 조달청이 제작하거나 후원한 게임이 아니며, 등장하는 기관·행사·업체·가격·수치는 모두 가상입니다. / 나라장터 접속·실제 입찰·온라인 접수 기능은 없습니다."
- 도움말(H/Esc): 위 문구 + 공식 단계 나열 + 대응표 + 출처 URL + "공식 로고는 사용하지 않았습니다."
- 공급안 화면 하단: "게임 규칙: 요청 조건·필요 수량·예산을 모두 충족해야 주문할 수 있습니다. 실제 공공조달의 업체 선정·계약 방식을 재현하지 않습니다."
- 요청서 제목: "조달 요청서 (가상)", 모든 기관명 뒤에 "(가상)".
- 공식 로고·기관 상징·나라장터 화면 모사: 사용하지 않음.

## 4. 사용하지 않은 것

- 나라장터 실제 API, 온라인 접수, 실제 입찰·계약 기능: 구현하지 않음(네트워크 통신 코드 없음).
- 실제 정부 사업·업체명: 사용하지 않음(기관·업체·행사명은 창작).
