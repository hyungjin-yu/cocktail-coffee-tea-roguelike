## 3. 구현하지 않은 것·미확인

- 나라장터 실제 API, 온라인 접수, 실제 입찰·계약·대금 청구: 없음(네트워크 코드 없음).
- 신규 아트·VFX·음향: 없음. 공모전판은 소리 없는 게임이다(AudioService 미생성 → 버튼 효과음 훅도 무음, 2026-11-11 정적 확인).
- 설정 화면(음량·해상도): 없음. 창 모드 1920×1080, 창 크기 조절 가능.
- 실제 입력(2026-11-11, `Delivery/Reports/qa-pps-real-input-2026-11-11.md`): 실제 마우스로 타이틀 시작 버튼 1회 PASS. 이후 출처를 알 수 없는 입력으로 진행되어 중단했고, 나머지 실제 마우스·키보드 경로, 붓기 길게 누르기, 사람이 플레이한 소요 시간, 창 크기 조절 표시는 미확인.

## 5. 조작

마우스 클릭만으로 모두 플레이할 수 있다(PlayMode 테스트에서 버튼 연결 확인). 키보드 대안(코드에 있으나 실제 키 입력으로는 미확인): 숫자키·Enter(요청 확인), 1~3·←/→·Enter(공급안), A/R(입고·반품), 숫자키·T·V·←/→·Space 길게·I(제조), X·B·Enter(검수), R·Backspace(결과·실패), H/Esc(도움말).

## 6. AI·도구 사용 범위

- Claude(Anthropic, Claude Code 에이전트): 공모전판 C# 코드·테스트·빌드·캡처 스크립트, 문서, 공식 절차 페이지 열람과 원문 인용 정리, 스크린샷 검수.
- Unity 6000.3.25f1(빌드·테스트), ffmpeg 9.0.1(영상 인코딩), Python(ZIP 생성·이미지 확인).
- 아트: 기존 「음료 마스터」 픽셀 아트를 재사용했다(기존 제작 기록상 Aseprite·PixelLab). 이번 작업에서는 이미지·영상·음성 생성형 AI를 쓰지 않았다. 영상은 실제 게임 렌더 프레임이다.

## 7. 신청서 담당용 사실 목록

완료형으로 써도 되는 것:
1. Unity 6000.3.25f1로 「음료 마스터」 본편과 분리한 공모전 전용판(v0.1.0-pps)을 만들었다. 시작 화면·저장 위치·제품명이 본편과 따로다.
2. 비알코올 커피·차를 다루는 가상 임무 3개를 담았다. 요청 확인 → 공급안 비교·선택 → 입고 확인 → 제조 → 검사·검수와 보완 → 납품 결과 흐름이다.
3. 가장 싼 공급안이 자동으로 정답이 되지 않는다. 조건(품명·성분·원산지 표시·수량·예산)을 충족해야 선택할 수 있고, 충족하지 못하면 사유를 보여 준다.
4. 검수에서 조건과 다른 물품은 인수되지 않는다. 불일치 사유와 보완 방법을 보여 주며, 보완한 뒤 다시 검수해야 납품할 수 있다. 중복 납품과 중복 보상은 막혀 있다.
5. 기존 픽셀 아트만 재사용했고 새 아트나 효과는 만들지 않았다.
6. 조달청 누리집 「물품구매 > 총액계약 > 업무처리절차」 페이지(https://www.pps.go.kr/kor/content.do?key=00179)를 참고한 단순화 창작 체험이다. 조달청이 제작·후원하지 않았다는 점과 나라장터·실제 입찰 기능이 없다는 점을 게임 안에 표시한다.
7. 자동 테스트 23개(EditMode 19, PlayMode 4)를 모두 통과했다. 1920×1080과 1280×720 실제 렌더에서 글자 넘침이 없음을 확인했다.
8. 시연 영상은 실제 게임 화면을 녹화한 1920×1080, 58초 영상이다. 캡처 전용 빌드 안의 자동 입력으로 진행했다는 표시가 화면에 있다.

아직 완료형으로 쓰면 안 되는 것: 사람이 직접 플레이한 소요 시간("2~3분"), 실제 마우스·키보드 전체 조작 확인(시작 버튼 1회만 확인됨), 접수 요강의 파일명·용량 요건 충족 여부(원문 대조 필요).

## 8. 재생성 방법

1. `Unity.exe -batchmode -quit -projectPath <worktree> -executeMethod CCT.Contest.ContestBuild.ReleaseBatch` (캡처본은 `CaptureBatch`)
2. 스크린샷: `Builds/PPSContestCapture/BeverageMasterPPS.exe -batchmode -pps-data-dir <임시> -pps-shots <폴더> -pps-size 1920 1080`
3. 영상 프레임: 같은 명령에서 `-pps-shots` 대신 `-pps-video <폴더>` → `ffmpeg -framerate 30 -i frame_%05d.png -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -movflags +faststart <mp4>`
4. ZIP: `Builds/PPSContest`에서 `*_DoNotShip` 폴더를 빼고 `Docs/Competition/README_실행안내.txt`를 더해 UTF-8 이름으로 압축한다.
