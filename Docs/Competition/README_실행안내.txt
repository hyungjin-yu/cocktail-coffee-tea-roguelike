음료 마스터: 공공조달 체험편 (버전 0.1.0-pps) — 실행 안내

[실행]
1. ZIP을 원하는 폴더에 모두 풀어 주세요(파일을 따로 옮기지 마세요).
2. BeverageMasterPPS.exe 를 실행합니다. Windows 10/11 64비트.
   (서명되지 않은 개인 제작 실행 파일이라 Windows SmartScreen 경고가 나올 수 있습니다. "추가 정보 → 실행")
3. 설치·인터넷 연결·로그인이 필요 없습니다. 창 모드 1920×1080으로 열리며 창 크기를 조절할 수 있습니다.

[게임 소개]
가상의 지역 행사에 필요한 커피·차를 요청 조건대로 준비해 납품하는 공급 협력자가 되는 짧은 체험 게임입니다.
임무 3개: 요청 확인 → 공급안 선택 → 입고 확인 → 제조 → 검사·검수(불일치 보완) → 납품.
임무 1은 입문 임무로 짧게 끝낼 수 있으며, 임무를 납품하면 다음 임무가 열립니다.

[조작] 마우스 클릭만으로 모두 플레이할 수 있습니다. 키보드 대안:
- 요청 확인: 숫자키(항목 확인), Enter(다음 항목 확인 / 진행)
- 공급안 선택: 1~3 선택, ←/→ 포장 수, Enter 주문
- 입고 확인: A 입고, R 반품
- 제조: 숫자키 재료, T 온도, V 용기, ←/→ 잔 수, Space 길게 눌러 붓기, I 검수 요청
- 검수: X 불일치 제외, B 제조로, Enter 납품
- 어디서나: H 또는 Esc 도움말·정책 해설·출처

[저장 위치]
%USERPROFILE%\AppData\LocalLow\PPSContest2026\BeverageMasterPPS\pps_contest_save.json (+ .bak)
「음료 마스터」 본편의 저장·설정과 섞이지 않습니다. 진행을 지우려면 이 폴더를 삭제하세요.

[안내]
이 게임은 공공조달의 요청·준비·확인 흐름을 단순화한 창작 체험입니다.
조달청이 제작하거나 후원한 게임이 아니며, 등장하는 기관·행사·업체·가격·수치는 모두 가상입니다.
나라장터 접속·실제 입찰·온라인 접수 기능은 없습니다. 공식 로고를 사용하지 않았습니다.
