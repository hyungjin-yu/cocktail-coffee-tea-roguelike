# 무한 모드 후속 작업 중단 — 2026-11-10

Claude 5시간 사용량 한도로 작업 중단. 안내된 초기화 시각 오후 1시 30분(Asia/Seoul). 재개 전 사용량 해제와 실제 착수 확인 필요.

현재 로컬 변경에서 확인한 것(완료/검증을 의미하지 않음):
- 웨이브와 생성 대기를 long으로 변경하고 999/5000 고정 상한을 제거하는 코드 작성.
- 정규 모드의 직업 테마/세 계열 선택 옵션 코드 작성.
- 적 이름·보스 배너·HUD의 계열 표식, FamilyLegend 신규 코드 작성.
- 관련 테스트 코드 수정 및 StandardFamilyTableTests 신규 작성.

이 후속 변경분의 컴파일·테스트·새 빌드·GUI 검증은 확인되지 않았다. 신규 파일 일부의 Unity .meta도 아직 없다. 이전 1차 빌드의 테스트 결과를 이번 후속 코드의 통과 결과로 사용하지 않는다.

주의: 극단적인 long 웨이브 누적 계산의 decimal 오버플로 등 수치 경계 추가 검토가 필요하다. 기존 미완 요구 및 안전한 실제 GUI 검증도 재개 후 확인한다. 런 중 음료 교체는 이번 범위에서 제외하며 신규 VFX도 보류한다.
