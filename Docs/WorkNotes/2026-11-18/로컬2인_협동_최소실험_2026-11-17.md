# 로컬 2인 협동 최소 실험판

사용자 승인: 시장성 논의 후 '한 PC 로컬 2인, 재료·음료 각 3종, 전투 구역 하나, 공간 이동으로 역할 교대' 최소 실험을 해보라고 지시했다. 온라인/모바일/계정·저장동기화·정식게임 전체전환은 범위가 아니다. 사용량 한도 내 완료는 보장하지 않으며, 진행·재개 기록을 남긴다.

## 보존과 진입

- 기존 싱글 코드·아트·미커밋 변경·11-17 검수본·공개 ZIP을 보존한다.
- 별도 Prototype 네임스페이스/폴더와 씬 또는 명시적 실행 인자로 진입한다. 기존 싱글 기본 실행 동작을 바꾸지 않는다.
- 실험판은 영구 저장·실제 재고/보상·결제를 사용하지 않고 런 메모리만 사용한다. 재시작은 실험판 상태만 초기화한다.
- 기존 승인 캐릭터·음료·재료·배경 아트를 재사용한다. 새 아트 생성은 선행조건이 아니다. 게임 제작/조율은 game-feel-first와 orca-unity-team 지침을 따른다.

## 플레이 범위

- 1PC 공유 화면 2명. 기본 입력: P1 WASD+E, P2 방향키+오른쪽 Ctrl(또는 충돌 없는 대체키). 키보드만으로 두 사람이 동시에 이동·제조·음용 가능해야 한다. 마우스 한 개 공유에 제조가 종속되지 않도록 한다. 조작은 화면에 명시한다. 게임패드는 이번 필수 범위가 아니다.
- 한 화면 안 전투 구역(바 홀)과 제조 구역(주방)을 문/카운터 경계로 시각 구분. 각 캐릭터가 경계를 넘어가면 즉시 전투/제조 역할 전환. 별도 교대 메뉴·직업 선택창 없음.
- 역할 고정/자동순간이동 없음. 둘 다 전투하거나 제조 가능. 한쪽이 비면 스폰/재료 수급/지원이 어떻게 달라지는지 자연스럽게 관찰한다. 충돌·문막힘·서로 다른 입력이 상대 캐릭터를 제어하는 결함이 없어야 한다.
- 전투는 이동+자동공격, 적 최소 1종과 단계별 압박. 처치한 적이 3종 재료 중 하나를 보장 규칙으로 공유 재고에 지급. 스폰 상한/성능 예산을 둔다. 원래 게임 난이도와 저장 시스템을 끌어오지 않는다.
- 재료 3종과 음료 3종은 기존 테마/아트를 바탕으로 실험 전용 간단 배합표를 문서화. 회복/잠깐의 공격지원/위기대응 중 서로 체감이 다른 3개 효과. 같은 효과의 이름·색만 바꾸지 않는다. 정확한 비용/시간/효과는 구현자가 최소안으로 정하고 보고서에 표로 남긴다.
- 제조 구역의 단순 작업대에서 키 입력으로 레시피 선택/제조. 공유 재료 차감은 확정 시 1회, 부족/취소/중복입력에서 음수·복제 없음. 취소 환불 정책 명시. 진행 표시·완성 잔 스프라이트·짧은 음소거 가능한 연출.
- 완성 잔은 공유 카운터에 제한 수량 보관하고 전투 담당이 받아 음용. 제조자가 완성 잔을 들고 밖으로 나가 싸우고, 전투자가 안으로 들어와 다음 잔을 만드는 교대가 가능해야 한다. 전달/수령/음용 키 안내와 잔 소유권·적용대상 표시. 원격으로 즉시 같은 잔을 두 명에게 적용하지 않는다.
- 체력·현재역할·3종재고·제조진척·대기잔·남은시간을 간단히 표시. 전투와 제조를 알아보는 것이 우선.
- 5분 생존 목표, 사망/성공 결과와 재시작·종료 제공. 두 사람 모두 사망 시 실패. 쓰러진 사람이 장시간 배제되지 않도록 안전한 부활/구조 최소안 명시. 무한 무적/QA 체력은 정상 경로에 넣지 않는다.
- Esc는 두 플레이어·적·제조타이머·효과시간을 모두 멈추며 재개 정상. 창 비활성 입력도 점검한다.

## 납품·검증

1. 별도 Windows 실행 폴더와 ZIP, 로컬 2인 전용 실행 cmd/README. 온라인 없는 로컬 실험판임을 명시.
2. 핵심 로직 검사: 입력 분리·역할경계 전환·동시재고차감/부족/취소·잔중복수령/음용 방지·효과만료/상한·재시작·Pause·성공/패배.
3. 실제 빌드로 두 플레이어 동시 이동, 제조→수령→음용→전투 효과, 양쪽 역할교대, 실패/재시작을 자동입력/화면으로 검증. fixture와 정상 시작을 구분. 720p/1080p 화면 확인, 정상 화면에 QA 숨김체력/강제재고 금지.
4. 기존 싱글 기동과 사용자 저장 파일 해시 불변 확인. 전체 오래된 시험을 불필요하게 반복하지 않고 관련 검사 실행.
5. 보고서에 구현범위·정확조작·실제테스트결과·빌드/ZIP/해시·사람2인 직접 플레이 미실시 한계·다음재개 지점을 남긴다.
