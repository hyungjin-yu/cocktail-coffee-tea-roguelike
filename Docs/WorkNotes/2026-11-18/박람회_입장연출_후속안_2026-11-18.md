# 박람회 모드 입장 연출 — 후속 작업

상태: 사용자 아이디어 기록만. **이번에는 구현하지 않는다.**

사용자 지시: 카페 입장형 첫 화면과 같은 느낌으로, 박람회 모드를 눌렀을 때 박람회장으로 이동하는 장면이 있고 추가 버튼을 눌러 박람회 모드가 시작되는 방식으로 나중에 진행한다.

## 예정 흐름

1. 기존 모드 선택에서 박람회 모드를 선택.
2. 카페에서 박람회장으로 이동하는 짧은 장면. 출발·도착이 공간과 분위기로 읽히며, 로딩 화면/페이드만으로 이동을 대체하지 않는 방향.
3. 박람회장 입구/준비 공간에 도착하여 장면을 보여주며 입력 대기.
4. `박람회 시작` 같은 명시적인 추가 버튼으로 실제 모드 시작. 이동 연출을 시작한 입력이 실제 시작 버튼까지 연달아 눌리지 않게 한다.

## 추후 설계할 사항

- 실제 출발점/이동 수단/박람회장 구도·동선·소품·현실성.
- 준비 화면의 정보·뒤로가기·재진입·연출 건너뛰기·저이펙트 처리.
- 기존 박람회 명세와 실제 모드 진입/자원차감/저장 처리 시점 대조. 단순 연출 때문에 중복 소모/정산이 생기지 않아야 한다.
- Aseprite+PixelLab 신규 아트 범위와 별도 구현·검증 기준.

이 기록은 향후 구현 실행·새 생성 비용·기존 박람회 규칙 변경을 승인한 것이 아니다. 현재 진행 중인 싱글 카페 첫 화면·칵테일 바 톤 통일 작업과 분리한다.
