# 플레이 피드백 26항목 개선 기획

2026-11-14 실제 플레이 피드백을 반영한 개선안이다. 사용자 지시 **“기획만 해”**에 따라 코드·아트·데이터·실행본을 변경하지 않는다. 아래 구체적인 화면 동작과 표현은 설계 제안이며, 이미 구현됐거나 개별 수치까지 확정됐다는 뜻이 아니다.

## 목표

처음 들어왔을 때 게임의 분위기를 느끼고, 그림으로 대상을 구분하며, 행동에 대한 피드백을 받아 다음 선택을 이해하게 한다. 첫 제조→첫 전투→결과·획득 확인→노트북 성장까지를 하나의 첫 플레이 경험으로 연결한다.

스프라이트 중심이라는 기존 방향을 유지한다. 핵심 효과·비용·조작은 짧은 글과 수치로 남기고, 긴 지식·출처는 별도 계층으로 분리한다. 시각적 강조는 실제 등급·목표·위험 상태를 전달하며, 판정과 무관한 번쩍임을 늘리는 데 그치지 않는다.

## 1. 첫 화면의 연출 강화

**요청:** 첫 페이지가 너무 평범하고 임팩트가 약하다.

**기획:** 야간 카페/바의 장면으로 시작한다. 어두운 공간에 간판·작업대 조명이 켜지고, 잔에 음료가 채워지거나 세 계열 대표 도구가 짧게 움직인 다음 타이틀과 시작 버튼이 자리 잡는다. 테마·음료·주인공을 한 장면에서 보여준다. 기존 승인 아트를 우선 활용하며 필요한 추가 그림은 제작 시 별도 목록화한다.

**동작:** 시작 버튼은 연출 종료를 기다리지 않고 사용할 수 있다. 클릭·키 입력으로 건너뛰기 가능, 재진입마다 긴 연출 강제 금지. 저이펙트 설정에서는 조명·움직임을 절제한다. 검은 화면에서 오래 대기하거나 연출이 입력을 삼키지 않게 한다.

**검수:** 첫 진입/재진입/건너뛰기/설정 변경에서 시작 동작 정상. 실제 영상으로 도입의 분위기와 전환 흐름 확인.

## 2. 도감 아이콘 확대

**요청:** 그림을 보고 무엇인지 알아볼 수 있게 키운다.

**기획:** 카드 한 칸에서 그림을 주인공으로 배치한다. 작은 그림 옆 긴 글 나열을 줄이고, 그림→이름→획득 상태 순으로 구성한다. 선택 상세에는 더 큰 그림과 효과·지식을 표시한다. 투명 여백 때문에 실물 그림이 작아지는 문제도 표시 영역 기준으로 조정한다.

**검수:** 720p에서도 서로 다른 대상의 형태가 구분된다. 확대 때문에 목록·스크롤·클릭 영역이 잘리지 않는다.

## 3. 미획득 도감의 잠금 표현

**요청:** 아직 못 얻었지만 나중에 얻을 수 있음을 알린다.

**기획:** 완전히 사라진 항목이나 일반 항목과 같은 표시 대신, 잠금 배지·옅은 실루엣·‘미발견’ 상태를 사용한다. 클릭하면 ‘플레이 중 획득하면 등록됩니다’와 허용된 획득 힌트를 보여준다. 항목 존재는 알리되 히든 스킬의 정답·숨은 조건을 자동 공개하지 않는다. 미획득 셀도 안내 상세를 열 수 있다.

**검수:** 미획득/최초 획득/재진입/기존 저장의 상태 일치. 색상만으로 잠금을 표현하지 않는다.

## 4. 커피 음료 종류 확대

**요청:** 라떼·플랫화이트 등 커피 종류 추가.

**기획:** 기존 추출법과 완성 음료를 분리한다. 에스프레소·핸드드립·모카포트는 제조 방식, 라떼·플랫화이트 등은 완성 음료 종류다. 1차 후보는 아메리카노·카페라떼·카푸치노·플랫화이트. 종류별 베이스·물/우유·거품·도구·완성잔을 명시해 단순 이름 변경을 피한다.

**설계할 항목:** 우유/거품의 실제 자원 표현, 스팀/거품 단계, 용량·헤드룸, 제조 미리보기, 품질, 레시피 저장·판매·런 음용의 연결. 신규 자원을 추가할지 기존 재료를 활용할지는 데이터 조사 후 확정한다. 현실 음료의 단일 배합이 절대 정답이라고 주장하지 않는다.

**전투 연결:** 베이스 추출 특성을 유지할지 완성 음료 특성으로 바꿀지 대응표가 필요하다. 여러 특성을 이름만으로 중복 지급하지 않는다. 종류만 추가하고 효과를 임의 배정하지 않는다.

**검수:** 다른 음료의 실제 제조 과정·잔 모양·재료 소비가 구분된다. 저장/취소/판매/음용이 같은 결과를 참조한다. 정확한 배합·효과·수치는 미정이다.

## 5. 음료 제조 튜토리얼과 단위별 따르기

**요청:** 1 단위 선택 제거, 단위를 누르면 지거로 따르는 애니메이션, 음료 1~2개를 만들며 제조 기능 안내.

**기획:** 기본 제조 UI에서 ‘1’ 단위 버튼을 제거한다. 내부 정밀도·기존 레시피 데이터까지 정수 단위로 바꾼다는 뜻은 아니다. 남길 단위는 기존 도구·레시피 필요량을 조사해 선정한다. 단위 버튼 클릭은 선택 표시만 바꾸지 않고 실제 재료→지거 따르기를 시작하며, 눈금·잔량과 전달량이 맞게 보인다.

**첫 실습:** 재료 선택→단위 선택·계량→지거 투입→제조 기법→완성 확인→보관→음용/판매 등 실제 기능을 단계별로 안내한다. 되돌리기·초기화·레시피 저장·불러오기 등 기존 기능은 실습의 적절한 지점에서 사용하게 한다. 커피 도구·차 우림처럼 구조가 다른 기능은 두 번째 예제 또는 해당 화면 첫 진입 안내로 보완한다. 한 잔으로 서로 배타적인 ‘마시기’와 ‘판매’를 둘 다 처리하지 않는다.

**자원·진행:** 필요한 양이 보장되는 튜토리얼 전용 재료 또는 구분된 지급 규칙을 설계한다. 실습 지급을 일반 판매 재화로 반복 환전할 수 없게 한다. 애니메이션 중 중복 클릭·닫기·건너뛰기로 중복 차감하지 않는다. 단계 취소·재개·다시 보기 제공.

**검수:** 초보자가 외부 설명 없이 예제 완성 가능. 각 단위와 지거 액면·소비량 일치, 재료 부족·취소·반복 안내에서도 저장·경제 정상. 구체적인 예제 레시피는 4번 커피 확장과 함께 정한다.

## 6. 재료 도감 검색·필터·잠금

**기획:** 상단 검색(이름·표시 설명), 계열/종류 및 발견 여부 필터, 검색 초기화를 제공한다. 결과 수와 빈 검색 결과 안내를 표시한다. 미획득 항목은 3번 잠금 공통 표현을 쓴다. 이름이 비공개인 항목은 비공개 이름으로 검색돼 정체가 새지 않게 처리한다.

**검수:** 검색과 필터 동시 사용, 초기화, 빈 결과, 한글 입력, 해금 후 목록 갱신, 긴 이름. 필터 전환 후 선택·스크롤 상태가 어긋나지 않는다.

## 7. 첫 판 종료 후 노트북 안내

**기획:** 첫 판의 사망·포기·클리어를 정산한 뒤 획득 내역을 확인하고 로비로 돌아오면 노트북을 강조한다. ‘이번 플레이로 얻은 재료와 연구를 확인해 보세요’처럼 다음 행동을 연결한다. 노트북 열기→연구 위치→보유 자원·가능한 성장 확인까지 안내한다.

**조건:** 첫 판이 끝났다는 저장 플래그와 안내를 마쳤다는 플래그를 구분한다. 연구를 살 자원이 없으면 자원 설명까지만 진행하며 강제 구매하지 않는다. 건너뛰기·다시 보기 가능. 결과·획득 화면을 건너뛰고 노트북으로 강제 순간 이동하지 않는다.

## 8. 레벨업 카드 좌측 상단 숫자 제거

**기획:** 카드에 붙은 선택 순번 등 불필요한 숫자를 없앤다. ‘1/2/3’ 키보드 선택 기능은 유지하며 화면 공통 하단 안내 또는 포커스 도움말에 짧게 표기한다. 중첩 수·비용·필수 효과 수치를 잘못 지우지 않도록 숫자의 의미를 먼저 확인한다.

## 9. 카드 게임 효과와 부가 설명의 글자 계층

**기획:** 제목→핵심 게임 효과→보조 설명 순으로 명확히 분리한다. 게임 효과의 글자를 키우고 수치·변화를 강조하며, 문화·제조 지식과 부가 설명은 작게 둔다. 짧은 효과만 키우고 긴 효과는 읽을 수 없게 자동 축소하는 방식은 피한다. 필요하면 줄 수·칸 높이·상세 보기로 해결한다.

**검수:** 짧은/긴 효과·최대 중첩·잠김·목표 표시 상태, 720p/1080p에서 비교. 설명을 줄여도 실제 효과를 잘못 이해하지 않아야 한다.

## 10. 지식카드 상세의 출처 가독성

**기획:** 게임 효과·지식 본문과 출처 영역을 나눈다. 출처는 작은 보조 글꼴·충분한 행간·명확한 제목으로 정리하고 긴 URL은 짧은 사이트명/문서명으로 표시한다. 출처 열기·복사 등 기존 기능을 보존하며, 본문 위로 겹치거나 전체 화면을 차지하지 않게 한다.

**검수:** 여러 출처·긴 주소·스크롤·본문 확대. 출처를 작게 하되 실제 읽을 수 있는 최소 크기는 유지한다.

## 11. 등급별 레벨업 카드 시각 효과

**기획:** 기존 등급에 맞춰 테두리 형태·배지·등장 연출을 구분한다. 일반은 차분하게, 희귀는 명확한 테두리와 짧은 강조, 상위 등급은 구별되는 실루엣·한 번의 등장 효과와 소리로 기대감을 준다. 배경 전체를 번쩍이거나 효과 본문을 가리지 않는다. 색각과 저이펙트 설정을 고려한다.

**주의:** 등급은 등급의 희소성과 성격을 표현한다. 현재 빌드에서 항상 최적 선택이라는 허위 추천을 하지 않는다. 등급 확률·카드 효과·추첨 규칙은 바꾸지 않는다.

## 12. 목표 진행 카드 강조

**기획:** 설정한 목표에 기여하는 카드에는 목표 문양·연결된 작은 카드 그림·진행 증가 표시를 사용한다. 마지막 조건을 채우는 카드는 ‘목표 완성’ 상태를 별도 강조한다. 등급 효과와 겹쳐도 목표 추천의 의미가 분리돼야 한다. 목표가 없으면 표시하지 않는다.

**검수:** 목표 미선택/일부 진척/완성/최대 중첩/같은 카드 재선택. 목표 기여와 일반 등급 강조를 사용자가 구분할 수 있다.

## 13. 이동 프레임 끊김 느낌 조사

**기획:** 우선 결함 가설을 분리한다. 보행 스프라이트의 프레임 간격, 이동과 카메라의 갱신 시점, 물리 보간, 픽셀 스냅, 프레임 시간 급등을 같은 이동 구간에서 비교한다. 증거 없이 애니메이션 프레임을 늘리거나 이동 속도를 바꾸지 않는다.

**검수:** 두 직업·네 무기, 좌우/대각 이동, 카메라 추적·경계, 한산한 구간·군중 구간에서 프레임 시간과 연속 영상을 기록한다. 물리 판정·피벗·공격 방향을 깨지 않고 자연스러워졌는지 실제 재생으로 확인한다.

## 14. 음료 재료 획득 시 스프라이트

**기획:** 획득 알림에 실제 재료 그림+수량을 표시하고 재고/진행 표시 쪽으로 짧게 이동시킨다. 월드 픽업과 화면 알림을 구분한다. 동시 획득은 같은 종류끼리 묶어 알림 폭주를 막고, 시각 효과를 생략해도 실제 획득량은 전부 집계한다.

## 15. 보스 접근 안내 강화

**기획:** 보스 초상·방향 화살표·경고 프레임·짧은 등장 소리를 결합한다. 보스가 화면 밖이면 방향을, 화면 안이면 실제 위치와 체력바 연결을 보여준다. 접근 예고와 이미 등장한 보스 위치 안내를 서로 다른 상태로 둔다. 일시정지·제조·튜토리얼 화면 위에 잘못 표시하지 않는다.

## 16. 공격 타격감 강화

**기획:** 실제 적중에 맞춘 피격 반응·짧은 섬광·타격 방향·적중음·무기 궤적을 우선 정리한다. 근접/총/활과 일반/강적·상성/막타를 구분하되 소리·파티클이 과하게 중첩되지 않게 한다. 작은 히트스톱·카메라 반응은 실험 대상으로 두고 다른 타이머·자동 공격 속도를 몰래 바꾸지 않는다.

**검수:** 빗나감·무적·0피해에는 적중 연출 없음. 다수 적중·연사·저이펙트·화면 흔들림0 설정에서 정상. 피격 반응 때문에 처치·재료·효과가 중복 발생하지 않아야 한다.

## 17. 우림 연구 좌측 상단 숫자 제거

**기획:** 노드 순번처럼 보이는 불필요한 숫자를 제거한다. 필요 포인트·보유 포인트·획득 단계·효과 수치는 남긴다. 키보드 단축키라면 노드의 주 시각 요소에서 분리해 공통 도움말로 옮긴다.

## 18. 우림 연구 스프라이트 세로 위치 수정

**기획:** 연구 노드의 그림을 텍스트·클릭 영역 기준으로 중앙 정렬하고 투명 여백·피벗·캔버스 배율을 함께 확인한다. 아이콘을 무조건 위로 이동하는 상수 보정 대신 공통 슬롯 정렬을 맞춘다.

**검수:** 차 변형 7종 포함 전 노드, 잠김/해금 가능/획득 상태와 720p/1080p에서 그림-단축키·제목·연결선 비겹침.

## 19. 활의 화살 종류 확대 — 검토 제안

**원문 성격:** 불화살·독화살 등을 늘려도 좋겠다는 제안.

**기획안:** 기본 화살, 불·독 화살을 기존 직접 적중 속성과 연결해 구분한다. 외형은 화살촉·꼬리·짧은 잔상·적중 표식으로 식별한다. 카드에 따라 자동 전환할지 명시적 선택을 제공할지는 미정이다. 기존 화염·독 부착이 이미 있으면 별도 중복 피해를 추가하지 않는다.

**결정 필요:** 동시 보유 시 표시 우선순위/혼합 표현, 습득 경로, 비용, 적용 무기. 새 기능인지 기존 속성의 표현 개선인지 먼저 확정한다. 삭제된 플레이어 중심 화염·독 지대를 부활시키지 않는다.

## 20. 몹 등급별 원거리 투사체 표현

**기획:** 일반·정예·보스가 같은 계열 공격을 해도 탄두 모양·테두리·꼬리 길이·적중 소리를 구분한다. 강한 공격일수록 위험이 읽혀야 하며, 실제 피해·범위와 어긋나는 과장은 하지 않는다. 효과 크기를 키워 실제 충돌 범위를 오해하게 만들지 않는다. 적탄과 플레이어탄도 명확히 분리한다.

**검수:** 군중·다중 투사체·배경색·저이펙트에서 판독. 피해량을 올리는 작업은 이번 시각 요청과 분리한다.

## 21. HP 20% 미만 긴박감 표시

**기획:** 현재 HP/최대HP가 **20% 미만**이면 HP 바 형태·경고 문양·완만한 맥동을 함께 표시한다. 화면 가장자리의 약한 경고와 제한된 경고음은 검토하되 지속적인 강한 화면 흔들림·점멸은 피한다. 회복 시 즉시 정상화하고 상태 경계에서 소리가 반복 폭주하지 않게 한다.

**검수:** 정확히20%/직전·직후/회복/최대HP변화/사망/새 런, 설정별 반응. 위험 신호가 적의 공격 예고나 조작을 가리지 않는다.

## 22. 종료 화면 ‘이번 판 빌드’ 문구 변경

**기획:** 버튼이 무엇을 보여주는지 알 수 있는 **‘성장·조합 보기’**를 1차 문구안으로 사용한다. 상세 제목은 ‘획득 카드와 완성 조합’. 실제 상세에 음료까지 포함한다면 ‘성장·음료 기록’처럼 범위를 맞춘다. 최종 문구는 화면 구성에 따라 확정하며 내부 저장 키를 바꾸지 않는다.

## 23. 종료 시 음료 획득 내역 확인 유도

**기획:** 결과 요약→이번 판 음료·재료 획득 내역→재시작/로비 흐름으로 구성한다. 두 번째 화면에 실제 획득 그림·수량·재고 반영을 보여주고 확인 행동을 다음 버튼으로 연결한다. 상세 재확인은 결과 화면에서도 가능하게 한다. 첫 판은 다음 노트북 안내와 이어진다.

**경계:** 획득0이면 빈 이유를 보여주되 불필요한 빈 화면 반복을 줄인다. UI를 확인했다고 보상을 지급하는 구조로 바꾸지 않고 정산은 기존 성공 시점에 1회만 한다. 강제 대기시간·여러 번의 확인창은 넣지 않는다.

## 24. 목표 음료 재료 획득 강조

**기획:** 기존 카드 목표와 별개로, 목표 음료 레시피를 고를 수 있는 위치를 마련한다. 목표 재료를 얻으면 재료 스프라이트가 목표 음료 슬롯으로 이동하고 ‘현재/필요’ 칸이 채워진다. 제작 가능해지는 순간 완성 상태를 한 번 강조한다. 일반 획득 알림(14번)과 하나의 피드백 체계로 통합한다.

**설계:** 이미 목표 음료 기능이 있으면 연결하고, 없으면 레시피 상세의 ‘재료 모으기’ 동작을 신설하는 안으로 둔다. 여러 목표 지원 여부는 미정이며 첫 구현은 활성 목표 1개가 기본 제안이다. 목표 해제·변경·제조로 재료 소비 후 상태도 갱신한다. 드롭 확률을 몰래 조정하지 않는다.

## 25. 히든 스킬별 UI 차별화 — 검토 제안

**기획안:** 모든 히든에 큰 개별 패널을 추가하는 대신 공통 HUD 틀 안에서 핵심 모티프·활성 상태·충전/지속 시간을 다르게 표현한다. 발동형은 짧은 활성 표식, 충전형은 개별 게이지, 상시형은 배지처럼 실제 동작에 맞춘다. 여러 히든 동시 보유 시 요약과 H 상세로 분리한다.

**결정 필요:** 실제 히든 목록별 발동·필요 정보·표시 위치·신규 아트 표. 스킬별 실제 메커닉을 조사하기 전 UI 형태와 개수를 확정하지 않는다. 전투 시야를 크게 점유하지 않는다.

## 26. 무한 모드 칵테일 음용의 취기 — 검토 제안

**기획안:** 취기는 칵테일의 분위기를 강화할 수 있으나, 예고 없이 좌우 반전을 넣으면 준비한 보상이 조작 불이익으로 느껴질 수 있다. 우선 지속시간이 있는 취기 배지·캐릭터 반응·절제된 시각 효과를 프로토타입으로 검토한다. 좌우 반전은 별도 취기 도전 옵션 또는 명시적으로 경고된 음료/규칙에서만 검토한다.

**결정 필요:** 확률·지속시간·발동 조건·얻는 이점·해제 방법·무적/일시정지/결과 전환과의 관계. 연속 음용의 누적 상한과 난수 재굴림 방지. 카메라 흔들림 설정0·저이펙트에서도 의도를 전달할 대체 표식. 현재 기본 모드에 임의로 랜덤 조작 반전을 추가하지 않는다.
