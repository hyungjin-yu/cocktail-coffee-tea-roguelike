## 실제 확인한 흐름

- 새 격리 저장과 게임이 기본 지급하는 재료만 사용해 제조 → 첫 주문 판매 → 150코인 지급을 확인했다.
- 같은 음료의 중복 판매가 거절되고, 앱을 다시 실행해도 코인·남은 재료·주문·판매 기록이 유지되는 것을 확인했다.
- 1280×720과 1920×1080에서 제조·판매 안내와 배치를 확인했다.
- 별도 QA 상태에서 음료 없음·다른 계열·재료 최소량 미달·다른 커피 추출 도구와 긴 레시피명을 확인했다.
- 일반 Windows ZIP을 새 폴더에 풀어 부팅·전투 시작·포기·결과 저장·재실행을 확인했다.
- itch.io 공개 파일을 다시 내려받아 업로드 패키지와 SHA-256이 일치함을 확인했다.

첫 제조·판매는 QA 전용 빌드가 실제 UI 콜백을 호출하는 자동 검수다. 추가 개발용 재료 지급은 사용하지 않았다. 경계 조건용 음료는 API로 준비한 QA 상태이며 일반 플레이와 구분한다. 사람의 학습 시간이나 병 드래그 조작감을 측정한 결과는 아니다.

## 자동 검사

| 검사 | 결과 |
|---|---|
| 11월 2일 최종 소스 전체 EditMode | 807개: 성공 806, 실패 0, 전제조건 보류 1 |
| 최종 소스 제조 관련 PlayMode | 60개: 성공 58, 실패 0, 증거용 건너뜀 2 |
| 저장 버그 수정 직전 소스 전체 PlayMode | 334개: 성공 326, 실패 0, 증거용 건너뜀 8 |

**저장 버그 수정 후 최종 소스의 전체 PlayMode는 메모리 부족으로 중단됐다.** 직전 소스 전체 검사와 최종 소스 관련 검사를 합쳐 최종 전체 통과로 표시하지 않는다. EditMode 보류 1건은 누락 아이콘이 있어야 실행되는 검사의 전제조건이 충족되지 않은 경우다.

## 남은 과제와 알려진 사항

- 최종 소스 전체 PlayMode 재검사
- 사람의 제조 조작감·첫 플레이 이해도와 장기 수급·성장 밸런스 평가
- 키보드만 사용하는 전체 화면 탐색 검수
- 매우 긴 경로에 압축을 풀면 Mono 로딩이 실패하는 문제: 짧은 폴더 사용 권장
- 종료 시 ComputeBuffer·D3D12 그래픽 자원 정리 경고: 재현됐으며 원인 미조사
