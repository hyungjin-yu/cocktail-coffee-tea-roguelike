## 아트 계약

대상 `ArtSource/skins-aseprite-pixellab-2026-10-20/`만 아트 담당 소유. 기존 게임 원본·이전2스킨을 실제 열어 비교하고 각 직업 필수 프레임 이름/사이즈/PPU/피벗/손 앵커 계약을 기존 Assets에서 읽는다. 바텐더 기존23프레임, 차 기존42프레임은 관찰값이며 실제 런타임 사용 프레임과 대조한다. 새 디자인은 idle/run/hurt/defeat/직업무기 동작 등 모든 사용 몸체 프레임에 일관되게 적용. 검 휘두르기 등에 무기가 기존 프레임 안에 있으면 기존 무기 부분은 보존한다. 프레임이 없을 때 기본 복장으로 번쩍 돌아가는 누락 금지.

Aseprite에서 실제 .aseprite 레이어·태그·native 재열기/PNG export를 납품한다. PixelLab은 설치된 Aseprite 확장 GUI로 실제 디자인 생성, 원본입력·프롬프트·성공출력·seed/관찰 가능한 생성기록을 보존한다. API키/계정설정/비밀값 읽지 않는다. PixelLab 생성 접근 불가면 즉시 코디네이터에 알리고 대체 생성기나 임시안을 최종으로 포장하지 않는다. 생성결과는 Aseprite에서 프레임별 수작업/Lua 편집 가능. 색 치환만은 금지, 절차로 만든 픽셀도 실제 디자인 차이·연속성을 검수한다.

합격: 각10종 native+PNG+명세 매니페스트(원본/출력 해시·프레임순서·피벗/앵커·생성기록·검수),10종 비교판, 종류별 idle/run/피격/쓰러짐/무기동작 대표 비교. 투명배경·알파/크기·잘림·손/발 기준·좌우 반전·실제 작은 표시크기·유사성 검수. 최종만 남기고 불필요한 대량 프레임 영상은 만들지 않는다. 아트는 ready, 게임 적용은 integrated/verified 별도.
