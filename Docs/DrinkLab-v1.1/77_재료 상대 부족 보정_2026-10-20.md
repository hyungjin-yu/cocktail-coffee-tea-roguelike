# 재료 상대 부족 보정 — 2026-10-20 개발 기준

사용자 ‘작업하자’에 따라 어제 남긴 재료 수급 조정을 이어간다. 아래 수치는 코디네이터의 가역적인 구현 기본값이며 사용자가 개별 수치를 확정했다는 뜻은 아니다.

## 이번 범위

기존 절대 보정은 6회분 이상에서 모두 같은 배율이 되어 상대 부족을 반영하지 못한다. 고정 묶음 수량, 획득처 기본 가중치, 일반 25킬 주기, 정예 및 중간/최종 보스 추첨 수·희귀 보장은 유지한다. 새 일반 드롭 상한은 이번에 도입하지 않는다. 수급 총량과 상대 편중을 먼저 분리해 측정한다.

각 추첨의 실제 후보 집합에서 재료별 회분 e=max(0, 창고+이번 런 미정산)/기준 사용량을 구한다. 후보들의 e 중앙값 m을 기준으로 배율 c=clamp((m+3)/(e+3), 0.5, 2.0)를 적용한다. 최종 확률은 기존 획득처 가중치×c를 정규화한다. 짝수 후보의 중앙값은 가운데 두 값의 평균. 후보가 하나면 배율 1. 후보가 아닌 희귀 재료는 일반 후보 중앙값에 포함하지 않는다. 희귀 보장에서는 희귀 두 종만 비교한다. 모두 같은 보유 회분이면 원래 획득처 확률을 유지한다. 적은 재료의 최종 확률이 기본 가중치가 다른 모든 재료보다 항상 높다는 뜻은 아니다.

여러 묶음은 앞 추첨 획득분을 다음 보유량에 포함한다. 전투 난수와 분리된 결정적 추첨, 저장 실패 재시도·중복 정산 방지, 기존 세이브/창고/RP/음료/유료 소유권을 보존한다. 실제 사용자 저장을 테스트에 사용하지 않는다.

## 관찰 가능한 합격 조건

- 동일 기본 가중치에서 6회분과24회분을 구분하고 부족한 재료가 우대된다. 같은 회분은 원래 확률, 0·큰 보유량에서도 유한한 합1 확률.
- 출처별 후보/희귀 보장/묶음 수량/결정성/미정산 반영/중복 정산을 관련 Edit·Play 검사로 확인한다.
- 이전 방식과 새 방식으로 같은 시드의 반복 추첨을 비교한다. 빈 창고, 균등한 풍부한 창고, 사용자 제보 잔고, 한 재료만 극단적으로 부족한 창고를 포함한다. 순획득과 최종 잔고를 구분하고 출처별 실제 추첨 수를 보고한다.
- 일반 500/2000/5000킬, 정예20회, 중간3회, 최종1회의 합성 조건에서 수급 총량을 보고한다. 사람의 실제 플레이나 확정된 경제 목표로 포장하지 않는다. 상한은 이 자료를 보고 후속 판단한다.
- 기존 hudfix를 보존하고 별도 2026-10-20 supply 빌드/ZIP, 해시, 새 폴더 격리 실행을 납품한다. 화면 구조 변경은 없으므로 불필요한 아트·전체 화면 캡처 순회는 하지 않는다.

## 코디네이터 독립 계산 기준

사용자 잔고에서 일반 후보 중앙값은18.5회분이다. 새 일반 확률 기대값은 진20.1621%·럼18.6868%·홍차20.7070%·녹차16.3013%·레몬10.9006%·꿀13.2423%. 이전 확률은18/18/18/18/14/14%다. 희귀 두 종은 일반 드롭 후보가 아니므로 일반 확률을 직접 늘릴 수 없다. 희귀 재고 부족은 정예·보스 표 안에서 비교한다.

지정 합성 조건의 실제 추첨 수는 일반500킬=20회,2000킬=80회,5000킬=200회에 정예20회+중간9회+최종6회를 더해 각각55/115/235회다. 같은 보상 안 동일 재료 합산으로 원장 기록 건수는 이보다 적을 수 있다. 이것은 정상이며 추첨 수 감소나 수량 손실로 해석하지 않는다.

이번 변경은 종류 편중 보정이며 총량 제한이 아니다. 높은 처치 수의 과도한 총수급과 실제 제조 소비량을 해결했다고 보고하지 않는다.
