## 자료 보관

- `ArtProduction/`: 원본·제작 및 검증 자료. 플레이 저장 데이터도 들어 있어 임의로 비우지 않습니다.
- Unity `ArtSource/`: Aseprite·PixelLab 원본. `Assets/`: 실제 게임 리소스·코드.
- `_기획_이력/작업기록/`: 오래된 제작·재개 기록. 삭제하지 않고 옮겨 보존했습니다.
- `SteamRelease/`: 향후 Steam 준비 초안. `UnitySamples/`: 과거 성장 시스템 연습 프로젝트.
- `지원서류/`: 제출 자료, 그대로 보존.
- `Upload/cleanup-result.json`: 이번 삭제 경로와 실제 확보 용량.

구형 빌드가 삭제돼 과거 보고서의 실행본·캐시 경로 일부는 더 이상 존재하지 않습니다. 해당 보고서는 당시 검증 기록입니다. 메인 Unity Library는 다음 개발 시 재임포트 시간을 줄이기 위해 보존했습니다. 외부 검증용 Library는 재생성 가능합니다.
