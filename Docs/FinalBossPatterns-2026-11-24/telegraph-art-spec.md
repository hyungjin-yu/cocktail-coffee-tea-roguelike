# 최종 보스 예고 아트 제작 규격 (Beverage Master #24, 2026-11-24)

대상: 바텐더 최종 보스 `진상 손님`(DifficultCustomer) · 찻집 최종 보스 `까다로운 차 손님`(TeaCustomer).
두 보스는 **같은 몸 아트(difficult_customer)·같은 드라이버(CustomerBossDriver)** 를 쓴다 → 예고 아트도 1세트 공용(찻집 전용 변형 불필요, 원하면 `tint` 변형 "tea"만).

표기: **[확정]** = 코드 판정/도형이 이미 고정(이번 작업에서 바꾸지 않음). **[잠정]** = 신규 패턴 가안 수치(Unity 실플레이 후 조정 가능, 도형 종류·원점·회전 규칙은 확정).

## 0. 공통 규격 (전 항목)

- PPU **128**, RGBA PNG, 2px 픽셀 격자, 모서리 투명. 프레임 파일명 `{id}_{clip}_{nn}.png` (기존 FeedbackArt 패턴), 원본은 `ArtSource/…`, 반입 경로 `Assets/_Project/Resources/FeedbackArt/{id}/` (반입·등록은 Unity 담당).
- **경계 = 알파 콘텐츠 상자.** 코드는 `ArtVfx.Band/GroundRing`으로 *알파 영역(ContentWorldSize)* 을 판정 치수에 맞춰 늘린다. 따라서
  - 띠(Band): 알파 상자 가로 = 판정 길이, 세로 = 판정 두께. **판정 밖 발광·그림자 금지**(안쪽만). 비균일 확대되므로 가로로 늘려도 깨지지 않는 무늬(가로 타일형, 끝 캡은 짧게).
  - 원(GroundRing): 판정 원이 타원 알파 영역의 **짧은 반축**에 맞춰진다 → 256×128 바닥 원 프레임이면 세로 반축 = 반지름. 테두리 선의 **바깥 가장자리 = 위험 경계**.
- 회전: 띠 아트는 **오른쪽(+X)이 진행/발사 방향**, 피벗 중앙(0.5,0.5). 코드가 임의 각도로 회전(조준선) 또는 0°/180°(벽)로 놓는다.
- 정렬: 바닥 예고 = `SortOrders.GroundZone(1)` (캐릭터 아래). 캐릭터를 가리는 불투명 채움 금지(2026-10-08 P1) — 채움 알파 ≤ 0.45 권장, 테두리는 진하게.
- 저이펙트(`HitFeedback.LowEffects`): 예고 자체는 **항상 표시**(판정 정보). 저이펙트에서는 첫 프레임 정지 재생만 쓸 수 있도록 **0번 프레임 단독으로 경계가 읽혀야** 함. 꼬리·흔들림·추가 섬광은 코드에서 생략.
- 용량: 프레임당 ≤ 16KB, 에셋당 총 ≤ 200KB 권장.
- 색: 기존 경고 계열(붉은 주황 테두리) + 손님 소재(영수증 종이·휴대폰 화면·별점 별). 아트가 없으면 코드가 `warning_line`/`warning_ring` 으로 대체하므로 **에셋 누락은 기능 저하 없음**.

| 패턴 | 판정 도형·치수 | 원점·방향 | 예고 시간 | 현재 그림 | 새 아트 ID(선택) |

## 2. 신규 패턴 A — "영수증 저격" (조준 원거리) [도형·규칙 확정 / 수치 잠정]

단계: **준비(조준 추적) → 고정(락) → 발사 → 회복**. 보스는 전 구간 정지, 몸 클립 `review` 재사용.

| 단계 | 그림 | 치수(월드) | 시간 [잠정] |
|---|---|---|---|
| 조준 추적 | 가는 조준선 띠 `final_aim_track` — 매 프레임 플레이어 쪽으로 회전 | 길이 **26**, 두께 **0.12**(가는 선) | 최초 노출 1.2s / 일반 1.0s / 분노(HP<50%) 0.75s |
| 고정(락) | 굵은 띠 `final_aim_lock` — 방향 고정, **이 띠의 두께가 실제 위험 폭** | 길이 26, 두께 **1.24** (= 2×(탄 0.22 + 플레이어 0.4)) | 일반 0.55s / 분노 0.45s |
| 발사 | 기존 `review_star` 탄 3발(보스 등급 테두리), 속도 13 | 탄 판정 r 0.22 | 0.08s 간격 |
| 회복 | 몸 정지(반격 여유) | — | 0.8s |

- 원점 = 휴대폰 앵커 `reviewOrigin`(없으면 보스 머리 위). 띠 중심 = 원점 + 방향×13, 각도 = atan2(방향).
- 분노(후반 강화): 1발 후 0.35s 이동 여유 → 2번째 조준(추적 0.5s·락 0.45s) 연속.
- 아트 요구: `final_aim_track` 256×16 가로 띠, 4f 반복 10fps(점선 흐름 → 오른쪽). `final_aim_lock` 256×32 가로 띠, 3f 비반복 12fps(테두리 점멸 → 마지막 프레임 유지). 끝에 휴대폰/영수증 소재 허용하되 **알파 상자 밖 금지**.

## 3. 신규 패턴 B — "폐점 클레임 러시" (최종 단계 복합) [도형·규칙 확정 / 수치 잠정]

발동: HP ≤ **30%** 최종 단계 진입 후, 2패턴마다 1회. 순서: **벽1(틈 있음) → 이동 여유 1.2s → 영수증 저격 1회(짧은 조준) → 여유 1.0s → 벽2(틈이 반대쪽) → 회복 2.0s**.

- "줄 서세요!" 영수증 벽: 레인 y = **-5.5 … 1.5, 간격 1.0 (8줄)**, 그중 **연속 2줄 비움**(안전 통로, 플레이어 중심 기준 빈 폭 1.76).
- 각 줄에서 `review_star` 탄이 보스 x에서 **좌·우 바깥으로** 속도 **7**, 수명 3s → 반경 **21**.
- 예고 그림 `final_queue_wall`: **연속된 줄 묶음마다 띠 하나**(통로 위·아래 최대 2묶음 × 좌우 2 = 띠 최대 4장).
  - 띠 길이 21, 띠 중심 x = 보스x ± 10.5, 각도 0°(오른쪽)/180°(왼쪽) → 아트의 +X 가 탄 진행 방향.
  - 띠 두께 = (묶음 첫 줄~끝 줄 간격) + 1.24. 예) 줄 3개 묶음 → 2.0+1.24 = **3.24**. 두께가 묶음마다 달라지므로 세로 늘림에 강한 무늬(가로 줄무늬·화살표 반복) 필요.
  - 예고 1.0s. 256×64 가로 띠, 6f 비반복 6fps(바깥쪽으로 흐르는 영수증/화살표가 점점 진해짐).
- 통로(안전) 표시는 **별도 아트 없음**(빈 공간으로 읽힘) — 회피 성공 문구·토스트도 없음(사용자 지시).

## 4. Unity 검증 포인트 (반입 후)

1. 띠·원 알파 경계와 판정이 일치: 락 띠 가장자리 0.62 바깥에 플레이어 중심을 두면 무피해, 안쪽이면 피격(신규 테스트 `FinalBossAimAndRushTests`).
2. 아트 누락 시 `warning_line/warning_ring` 대체로 같은 테스트가 통과(도형 판독 대체).
3. 720p·4:3에서 벽 띠·조준선이 HUD 상단 배너/하단 바와 겹쳐도 경계가 읽히는지, 저이펙트에서 0번 프레임만으로 읽히는지.

## 5. 구현 현황 (코드 반영, 2026-11-24)

- 순환: 환불 → 소환 → 별점 → 주문 부정 → **영수증 저격**(5번째, 첫 등장 약 32초). HP ≤ 30% 진입 시 **폐점 클레임 러시**를 바로 다음 패턴으로, 이후 일반 패턴 2개마다 반복. 한 번에 한 패턴만 실행(`busy` 가드)하고, 러시 뒤에는 회복 2초 + 다음 패턴까지 2.5초.
- 피해 가안(보스 공격 배율 ×1.75 적용 전): 저격 18(분노 20), 벽 탄 10. 피격 무적 0.8초라 같은 줄의 연속 탄은 실제로 1회 피해. 저격만 빠른 단일 선(속도 13)이고, 별점의 둔화와 리바이어던의 수평 증기 즉발과는 역할이 겹치지 않음.
- 탄 상한: 적 탄이 140발 이상이면 저격·벽 탄을 더 만들지 않음. 러시 1회 최대 생성량 = 벽 12 × 2 + 저격 3 = 27발.
- 일시정지·보상창(timeScale 0): 조준 추적·대기 모두 멈춤. 보스 사망·파괴 시 진행 중 예고를 즉시 정리하고 발사하지 않음.
- 저이펙트: 예고 아트는 0번 프레임 고정, 카메라 흔들림 없음, 탄 꼬리 없음(기존 규칙).
- 회피 성공 문구 제거: "환불 회피!" 배너 삭제(사용자 지시). 신규 패턴에도 회피 성공 표시 없음. 피격·예고·안전 통로는 그대로.
- 엔드리스(마스터 도전) 모드에는 최종 보스가 없음(Director 스케줄 비움). 박람회 손님은 boss=None·드라이버 없음 → 영향 없음.
- 저장 형식 변경 없음.
- 예고 아트 반입: `Resources/FeedbackArt/final_*`(25프레임, 128 PPU, Point, FullRect, 무압축, 별점 부채 커스텀 피벗 0.04539). `FeedbackArt`에 알파 상자(content)를 등록해 Band/GroundRing이 경계를 정확히 맞춤. 아트가 없으면 `warning_line`/`warning_ring` + 정확한 단색 채움으로 대체.
- 효과음 재사용: 조준 고정 `spell`, 저격 발사 `shot_gun`, 벽 예고 `steam`, 벽 발사 `shot_hybrid`. 전용 효과음은 아직 없음(필요하면 별도 인계).
