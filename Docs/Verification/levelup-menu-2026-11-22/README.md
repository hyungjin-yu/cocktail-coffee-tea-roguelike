## 항목 8 후속 (2026-11-23) — 카드별 전달·재생 속도·모드별 포커스

- **카드별 고유 전달**: 공통 클립 한 번(최고 등급) 대신 카드마다 자기 등급(일반·희귀·영웅) 클립을 실제 직업 외형(바텐더/차 소믈리에)으로 그 슬롯에서 동시에 재생한다(`CardSelectView` 슬롯별 `MenuHandoffPlayer`, 이미지 `MenuHandoff1..3`). 판 앵커는 그 카드의 시작 좌표(최종 가로 오프셋 88%, Y −30)라 마지막 포즈의 메뉴판이 그 카드로 이어지고, 카드는 자기 전달이 끝나는 시점에 70 ms 페이드·94→100%로 정착한다. 입력(키·마우스·터치·슬롯 버튼)은 마지막 카드가 정착한 프레임에 `InputReleaseGate`를 새로 무장한 뒤 열린다. 384 폭 < 시작 간격 422(3장)·422(2장 ±211)라 캐릭터끼리 겹치지 않는다. 아트 HANDOFF 1항의 "최고 등급 공통 클립"과 다른 의도된 변경(작업 지시). 새 아트 없음 — 기존 `Resources/LevelUpMenu` 41 PNG 재사용.
- **재생 속도**: 설정 `levelUpAnimPercent`(settings.json v2에 필드 추가, 기본 50 = 0.5배 ≈ 원본 2배 길이, 25~200 정리, 키 없는 예전 파일 = 50, 기본값 복원 포함). 설정 화면 왼쪽 열 "레벨업 연출 속도" 0.5→0.75→1→1.5→2배 순환(모바일은 다른 줄과 함께 위로 당김). 원본 프레임 ms 표는 그대로, 벽시계 delta × 속도로 누적. 한 번 연 창은 시작 때 속도 고정. 하이브리드 특수 해금도 같은 설정. 효과 강도 '낮음'은 속도와 무관하게 즉시 정착(값 칸에 "효과 낮음: 즉시").
- **모드별 조사**: 카드 창은 진상 보스 영업·마스터 도전·모바일 터치에서 같은 화면이다. 덮개(0.96 검정, 레이캐스트 차단)가 마우스·터치를 막고 B(제조)·H·K는 `State` 검사로 이미 막힌다. 모바일은 키 안내·[T] 표기가 이미 숨겨짐. 남은 누수는 **키보드 자동 이동**이 덮개 아래 HUD(일시정지·조작 방식·히든·목표) 버튼이나 마스터 도전 준비 패널(반복·박람회·전투 시작·음료 만들기)로 포커스를 넘기는 경로였다 → 카드·지식 버튼·목표 바꾸기·학습 안내만 잇는 명시 이동으로 묶고, 비어 있는 슬롯·숨긴 목표 버튼은 대상에서 뺀다. 닫힐 때 다음 화면이 포커스를 가져가지 않았으면 열기 전 포커스(예: 준비 패널 버튼)를 되돌린다(연속 보상은 처음 포커스를 들고 감). 진행·필수 조작(선택·목표 바꾸기·학습·Esc 일시정지)은 그대로.
