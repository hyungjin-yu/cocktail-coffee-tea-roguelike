## 3. Unity 후속 검수 목록 (#13과 공동 검수 때)

해상도 1280×720 / 1920×1080 / 1440×1080(4:3), 바텐더·티 소믈리에, 표준·마스터.

1. **컴파일 + 테스트**: EditMode `UiReadabilityTests`(신규 4건 포함), PlayMode `PauseTests`, `HudHazardOcclusionPlayTests`, `PlayFeedback1122PlayTests`, `MasterChallengePlayTests`, 카드 창 관련(`PlayFeedback1122Tests`, `CardEducationPlayTests`), AutoTour UI 상태(`AutoTourUiStates` 25~26번 장면).
2. **일시정지 위 카드 창**(E-E 재촬영): 사유가 연구 버튼 안 아랫줄에 보이고 "설정" 버튼과 겹치지 않음, 라벨과 사유가 서로 닿지 않음.
3. **상단 게이지**: 3단(바텐더)·2단(차)에서 줄 사이 겹침 0, 원두 줄 "(스킬 u/n)"이 바 안. 레벨업 펄스(세로 1.25배) 중에도 인접 줄 침범 여부. 안내 띠(RunGuide)와 바탕 사이 간격, 보스 배너 제목(−202)과 안내 띠(−144..−194) 비겹침.
4. **디버프 줄**: 1종·2종·4종 동시(환불+이동+공격+회복) 글자 최소 크기(목표 ≥ 13px@720p), 아이콘 5칸과 글 비겹침. **커피 연구 표시(우상단)·새 음료 패널(#13 칩)과의 공존** 포함.
5. **마스터 준비/선택 패널**: 제목·블록 머리 1회씩, 하단 줄이 18pt 이상으로 한 줄에 들어가는지, 버튼과 비겹침.
6. **마스터 제조 창**: 재료 부족 행 "재료 부족" 버튼이 비활성 스프라이트+회색 글자로 구분되는지, 구역 제목 폭(760px) 안.
7. **카드 창 미리보기**: 최대 체력/게이지 필요량/추가 드랍 카드에서 둘째 줄이 효과 상자(92px) 안, 지식 문구·이름판과 비겹침, 22→16pt 맞춤. 카드 등장·건네기 연출 중 위치.
8. 감사의 남은 [S] 화면: 결과·설정(해상도 확인 문구)·튜토리얼·보스 배너·ActiveEffects 칩·도감·서랍 캡처 1회씩.
