# #22 바닥 위험(물기·얼룩) — 디버프 몹 자동 등장 대체 (2026-11-24)

상태: 코드 + 가벼운 검증만(Unity 미실행). 런타임 검수는 아래 계획대로 Unity 배치가 비면 진행.

## 규칙 (사용자 정정 반영 — 최신 지시 우선)
1. 예고: 판정 경계와 같은 테두리 링(`ZoneTelegraphV2`)이 `WarnSeconds`(1.5초) 동안 안쪽에서 차오름.
2. 생성 순간: 플레이어 위치와 무관하게 해당 디버프 **즉시 적용** (물기 → 미끄러짐, 얼룩 → 스트레스).
3. 진입 → 구역 안 **연속 체류 `FloorHazardRules.CleanSeconds`(잠정 3초, 이 상수 한 곳에서 조정)** → 청소 완료 = 그 구역 + (같은 계열 남은 구역이 없으면) 디버프 즉시 제거.
4. 구역을 나가면 연속 체류 카운터 0. 이탈·시간 경과로 디버프가 풀리지 않음, 구역 자연 소멸 없음(해제는 청소만).
5. 같은 계열 여러 곳 = 효과 1단계(비중첩), HUD에 곳 수 표시. 각 구역은 개별 청소.
6. 예고 중 체류는 청소로 세지 않음. 사망 중 청소 없음. 일시정지·선택 창(timeScale 0)·재개 카운트다운 중 진행 없음.
7. 런 종료(GameOver) 즉시 구역·디버프·오라 정리, 리트라이/타이틀은 스포너와 함께 Destroy(OnDestroy에서 스탯 플래그 해제).

## 검수용 가안 수치 (`FloorHazardRules`)
| 항목 | 값 |
|---|---|
| 첫 등장 / 간격 | 120초 / 30초, 300초부터 20초 (물기·얼룩 번갈아) |
| 예고 | 1.5초 |
| 동시 상한 | 총 3곳, 계열당 2곳 (상한이면 다른 계열, 그래도 차면 대기; 밀린 차례는 1개만 유지) |
| 연속 생성 유예 | 생성·청소 후 8초 |
| 반경 | 물기 1.1 / 얼룩 1.0 (판정 원 = 웅덩이 불투명 영역 = 예고/청소 링 테두리) |
| 배치 | 플레이어 중심→구역 가장자리 ≥2.2, 중심 거리 ≤7, 시작 지점 가장자리 ≥3, 구역 간 간격 ≥0.8, 레인·전투 구역·화면(가장자리 1.6 여유) 안, 16회 시도 후 실패면 다음 틱 |
| 미끄러짐 | 목표 속도로 0.3초에 맞춰지는 관성(멈추면 현재 방향으로 약 0.75 유닛 미끄러짐), 서 있으면 힘 없음, 속도 상한 = 이동 속도 |
| 스트레스 | 공격 속도 ×0.85 (-15%), 다른 공속 감소와 곱 |
| 청소 | 연속 3초 (잠정) |

## 모드 범위와 근거
- **정규 모드(바텐더·차 소믈리에 모두)**: 기존 디버프 몹이 자동 등장하던 유일한 경로(`EnemySpawner.TickDebuffMobs`)를 바닥 위험으로 대체. 보스전 중 생성 쉼(기존과 동일), 기존 구역 청소는 가능.
- **끝없는(마스터 도전) 모드**: 기존에도 디버프 몹이 없던 범위 밖 모드라 확대하지 않음(`ModeHasHazards`). 확대하려면 마스터 웨이브 목표·준비 정지와의 상호작용을 별도로 정해야 함.

## 호환
- `EnemyDef.BitterMist/GlassThief`, 아트, `MonsterFamilies` 분류, 드라이버, `DebuffMobSchedule`, `SpawnDebuffMob`(QA 투어·시험) 유지. 자동 일정만 `EnemySpawner.AutoDebuffMobs = false`(되돌리기 1줄).
- 세이브·도감: 몹 도감 ID 기록 없음(도감 = 카드·음료·재료), 런 기록은 처치 수만 — 새 저장 필드·ID 없음. 바닥 위험 상태는 런 메모리 전용.
- 처치 수: 디버프 몹(30초마다 1마리) 처치가 빠져 정규 런 처치 수가 조금 줄 수 있음(재료 드랍 0이라 경제 불변).
- 시험: `PlayFeedback1122PlayTests.DebuffMobs_*` → 120초 자동 몹 0 + 바닥 위험 1 + 수동 경로로 기존 몹 검증. 스포너를 끈 시험에는 바닥 위험 생성 없음(일정은 스포너 Update 경로).

## 런타임 검수 계획 (Unity 배치 가능할 때)
1. EditMode 전체 + PlayMode `FloorHazardPlayTests`, `PlayFeedback1122PlayTests`, `HudHazardOcclusionPlayTests` 실행.
2. 정규 런 바텐더/차 각 1회: 120초에 예고 링 → 웅덩이 생성 즉시 HUD 상태 줄 "미끄러짐(물기 1곳) · 구역 안 3초 머물러 청소" + 오라.
3. 진입 → 청소 링 안쪽 차오름 확인, 1초 후 이탈 → 링 0 복귀·디버프 유지, 재진입 3초 → 구역·HUD 문구·오라 같은 프레임 소멸.
4. 물기 2 + 얼룩 1 동시: 공속 1단계, 곳 수 표시, 하나씩 청소 시 해당 계열만 해제.
5. 미끄러짐 체감: 키보드·터치 조이스틱에서 멈춤 미끄러짐이 짧고 벽/레인 경계 넘지 않음, 서 있으면 정지 유지.
6. 시인성: 720p/1080p/4:3, 좌측 HUD 패널·터치 조이스틱 근처 구역 → HUD 반투명 처리, 적 예고(돌진 띠·장판 예고)와 겹칠 때 판독, 저이펙트 설정.
7. 오라: 일반 = 숨쉬는 먹빛/짙은 보라 외곽, 저이펙트 = 고정, 몸·무기를 덮지 않음, 차 소믈리에 음료 오라(밝은 잔물결)와 동시 표시 구분, 마지막 디버프 청소 즉시 소멸, 둘 이상이어도 한 겹.
8. 일시정지·레벨업 카드·마스터 준비 중 진행 정지, 사망/포기 결과 화면에서 구역 즉시 정리, 리트라이 후 잔존 없음.
9. 프로파일: 구역 ≤3곳(곳당 렌더러 2~3 + 오라 4), Update 1개 + 구역 순회만.

## 아트 (기존 우선 활용)
- 물기: `zone_tea_pool_v2`(초록 차 웅덩이)에 물빛 틴트(0.7,0.95,1) — 녹색 기가 남을 수 있음.

- 전용 스프라이트 명세(필요 시): `floor_water_puddle`, `floor_stain_spill` — 바닥 효과 256×128 센터 피벗, 4프레임 10fps 루프(잔잔한 반짝임), 불투명 영역 = 판정 지름(가로 세로 같은 비율로 맞춤), 물기 = 투명 하늘색 반사광, 얼룩 = 짙은 갈색·자주 테두리, 가장자리 1~2px 진한 윤곽(판정 경계 판독), 캐릭터를 가리지 않도록 중앙 알파 ≤0.75. `ArtExtra/<id>/<id>_00..03.png`로 넣으면 `FloorHazardRules.ArtId`만 교체.
